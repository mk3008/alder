## 業務上の確認が必要な点

1. 点検は「受付済みの返却品を受け取ったとき」に始めるのでしょうか。それとも「点検済みであることを確認してから」でしょうか。後者なら「点検済み」は何を指しますか。前者なら、点検実施者は受付済みの品を誰からどう受け取りますか。
2. 点検を実施し、故障の有無を判断して点検結果を記す役割は誰ですか。
3. 故障の有無を判断する材料と基準は何で、その材料を誰からどう受け取りますか。

任意の改善案として、上の業務上の意味を確認した後に、QR読取や追加承認の案を必要性・負担とともに別途比較できます。現時点の業務には採用していません。
