# 備品返却業務の業務設計書（合意前の草案）

返却受付と、受付済みの返却品の点検を扱う。業務上の合意はまだない。部長の追加承認とQR読取機能は会議後の改善アイデアであり、この草案の決定済み業務には含めない。

**未確認事項（人の判断が必要）**

- 「返却品を点検する」の開始条件：会議前半の「受付済みの返却品を受け取ったら開始」と、後半の「点検済みであることを確認してから開始」が矛盾している。どちらが点検の開始条件か。後半の「点検済み」が何を指すのかも確認が必要。前半案なら、点検実施者が受付済みの品を誰からどう受け取るかも未確認。
- 「返却品を点検する」の担当：点検を実施する役割は未定。誰が故障の有無を判断して点検結果を記すか。
- 「返却品を点検する」の判断：故障の有無を判断する材料・基準、その材料を誰からどう受け取るかが不明。何を根拠に判断できるか。必要な情報の受け渡しは、回答後にInputへ反映する。

# Activity 返却を受け付ける

## Scope

true

## Why

返却品の受付を記録し、返却者に受付番号を知らせるため。

## When

返却者が返却品と管理番号を受付担当へ渡したとき。

## Who

受付担当

## Where

備品受付窓口

## How

### Input

- 返却者 — 返却品 / 管理番号

### Procedure

1. 受付担当が返却者から返却品と管理番号を受け取る。
2. 返却台帳へ管理番号と受付番号を記録する。
3. 受付番号を記した返却控えを返却者に渡す。

### Output

- 返却品 — 受付済みの返却品
- 返却台帳 — 管理番号 / 受付番号
- 返却者 — 受付番号を記した返却控え

## Result

受付番号が返却台帳に記録され、返却者が返却控えを受け取った状態となる。受付済みの返却品は点検の対象となる。点検の開始条件は未確定。

# Activity 返却品を点検する

## Scope

true

## Why

受付済みの返却品について故障の有無を判断するため。

## When

未確定。会議前半は「受付済みの返却品を受け取ったら開始」、後半は「点検済みであることを確認してから開始」と説明され、どちらを採用するか決まっていない。

## Who

未定（点検実施者）

## Where

備品受付窓口

## How

### Input

- 返却品 — 受付済みの返却品

### Procedure

1. 点検実施者（未定）が受付済みの返却品について故障の有無を判断する。判断の材料・基準とその受け取り方は未確認。
2. 点検結果へ状態を記す。

### Output

- 点検結果 — 状態（故障の有無）

## Result

故障の有無を判断した状態が点検結果に記されている。
