# Activity 返却を受け付ける

## Scope

true

## Why

返却した品と受付の記録を対応させる。

## When

返却者が返却品と管理番号を受付担当へ渡したとき。

## Who

受付担当

## Where

備品受付窓口

## How

### Input

- 返却者 — 返却品 / 管理番号

### Procedure

1. 受付担当が返却者から返却品と管理番号を受け取る。
2. 返却台帳へ管理番号と受付番号を記録する。
3. 受付番号を記した返却控えを返却者へ渡す。

### Output

- 返却台帳 — 管理番号 / 受付番号
- 返却品 — 受付済みの返却品
- 返却控え — 受付番号を記した返却控え
- 返却者 — 受付番号を記した返却控え

## Result

受付番号が返却台帳に記録され、返却者が返却控えを受け取っている。受付済みの返却品が点検の対象となる。
