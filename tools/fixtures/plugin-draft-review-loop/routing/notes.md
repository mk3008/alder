# 備品返却の聞き取りメモ

これは社内備品返却の新しい業務設計の材料です。業務の合意はまだです。
- 返却者が返却品と管理番号を受付担当へ渡したとき、返却受付を始めます。受付担当は管理番号を受け取り、返却台帳へ管理番号と受付番号を記録します。返却者に受付番号を記した返却控えを渡します。返却受付の終了は受付番号が返却台帳に記録され、返却者が返却控えを受け取った状態です。
- 受付済みの品は点検します。点検を実施する役割はまだ決まっていません。
- 点検の開始について、会議の前半では「受付済みの返却品を受け取ったら開始」と説明され、後半では「点検済みであることを確認してから開始」と説明されました。どちらが正しいかはその場で決まりませんでした。
- 点検では故障の有無を判断し、点検結果へ状態を記します。ただし故障の有無を判断する材料・基準と、誰からどう受け取るかはメモにありません。
- 点検をする場所は備品受付窓口です。受付も同じ窓口です。
- 部長の追加承認とQR読取機能は、会議終了後に出た改善アイデアです。現行の業務ルールとして決まったことではありません。
