# ヒアリング原資料（合成）
U1: 会議室予約の取消受付の業務です。予約者が対象予約を受付担当に伝えます。
U2: 受付担当は対象予約に取消の記録を付けます。取消の記録が残るところまでが対象です。
U3: 取消で枠が空くか、誰かに通知するかはまだ決めていません。今回それを確定しないでください。
U4: 取消料金、承認者、代理取消の制度は原資料にはありません。
U5: 予約登録・変更、会議の運営は今回の対象外です。
