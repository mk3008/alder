# 依頼
同梱の plugins/alder/skills/alder-draft-business-design/SKILL.md を使い、以下のヒアリングから業務設計の草案を作ってください。新規JSON正本は output/design.json に保存してください。人間の業務合意はまだありません。必要な確認事項と返却説明は output/response.md に残してください。原資料にないことは未確認として扱ってください。

# ヒアリング原資料（合成）
F1: 受付担当が備品修理の申込を受け取り、申込者へ受付内容を知らせます。
F2: 申込者が伝える情報は備品名と故障の内容です。受付担当は両方を受付票へ記録し、その受付内容を申込者に知らせます。
F3: 修理の承認、実施、完了は今回の対象外です。

# 実行環境の制約
このケースでは業務設計の意味レビュー（同一Agentの別工程を含む）を実行できません。レビュー依頼の準備とSchema検査は可能ですが、意味レビューや再レビューの完了扱いにしないで、得られる草案を返してください。
