# 依頼
同梱の plugins/alder/skills/alder-draft-business-design/SKILL.md を使い、以下のヒアリングから業務設計の草案を作ってください。新規JSON正本は output/design.json に保存してください。人間の業務合意はまだありません。必要な確認事項と返却説明は output/response.md に残してください。原資料にないことは未確認として扱ってください。

# ヒアリング原資料（合成）
N1: 社内説明会の申込を受付担当が受け取り、受付内容を申込者に知らせる業務です。
N2: 申込者は氏名、希望日、連絡先を受付担当へ伝えます。
N3: 受付担当は受け取った氏名、希望日、連絡先を申込台帳に記録します。
N4: 記録後、受付担当は申込者へ氏名と希望日を知らせます。申込者は自分の受付内容を知ります。
N5: 承認、参加枠の確保、料金の徴収は今回の業務にはありません。連絡手段は決めていません。
N6: 受付内容を申込者が知るところまでを草案の対象とし、説明会の開催や当日の参加確認は対象外です。
