# 反証用の架空共通契約

**評価専用。実際の人間判断・Business Designの変更ではない。** 初回出力後にN01–04を再照合するために用意した。既存入力全体に以下が追加されたという仮定だけで評価する。

- H01: 利用日時はすべてAsia/Tokyoの業務時刻として入力・比較する。この対象範囲で別時間帯の入力は受け付けない。
- H02: 予約時点・変更時点とは、その操作の成立条件を検査する際に取得した時刻を指す。検査後から保存完了まで開始日時が未来である保証は要求しない。
- H03: 変更・取消は指定IDの現在内容に対して行う。本人が以前見た内容と異なることだけを理由には拒否しない。本人・状態・日時・競合等の既存条件は維持する。
- H04: 呼出しの再送があり得るか、同じ意図の要求をどう区別するかについて、この架空契約は何も追加しない。

課題: 初回のoutput.mdのN01–04をこの仮定の下で再照合し、再質問すべきでない項目、残る項目、追加してはいけない保証を記録する。新しい候補を増やさない。
