### AR-03 結果説明から作業成果の確認へ進める

**条件：** AIが結果説明を既存の Chat または関連する Issue / PR の応答に含めて返したとき。

**期待結果：** 依頼者が結果説明から目的との対応、根拠の参照、未完了事項と必要な判断を把握し、作業成果の確認へ進める。要約は原典を置き換えない。

### AR-04 改善提案の採否と効果を区別して説明する

**条件：** 作業結果に改善提案が含まれるとき。

**期待結果：** 提案にカテゴリまたは改善効果の分かるタイトルがあり、減らす仕事の場面と人間に残す判断が示され、候補・採用済み・未実施の区別が分かる。

<a id="ar-07"></a>
### AR-07 訂正または業務判断を確認結果として伝える

**条件：** 依頼者の確認で、次のいずれかに該当する場合。

- 意図の逸れ・不足がある。
- 業務上の意味や候補の採否に判断が必要である。

**期待結果：** 該当する訂正内容または判断・採否が、依頼者の確認結果としてAIへ伝わり、後続の作業へ進める。

**人間レビュー状態：** 未レビュー

- 導出分類：明示。AI確度：高。レビュー優先度：通常。
- Test/assertion：未作成・未照合。

## Object 結果説明・確認結果：情報の引継ぎ

[AI作業結果を返す](#activity-return)は、Object 依頼内容と作業成果を入力に、Object 結果説明を既存の応答に含めて返す [AR-01](#ar-01)、[AR-02](#ar-02)、[AR-03](#ar-03)、[AR-04](#ar-04)、[AR-05](#ar-05)。[AI作業結果を確認し訂正を伝える](#activity-review)はその説明と原典を確認し [AR-03](#ar-03)、[AR-06](#ar-06)、Object 確認結果で訂正・判断をAIへ返す [AR-07](#ar-07)。採否の無回答は [AR-08](#ar-08) を参照する。これらの Object に状態遷移は定義されていない。訂正後の修正実行や恒久的な引継ぎ方法はこの設計の対象外である。
