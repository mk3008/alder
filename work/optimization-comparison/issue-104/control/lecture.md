# 講演会運営 Business Design（合成事例・現状）

この小さな業務は市民資料館の資料業務から独立している。件数、待ち時間、損失などは提示されていない。

# Object 講演会案内

## Scope

true

## Icon

file-text

## Information

- 講演会名、日時、一般公開する説明文

# Object 講師謝礼の証憑

## Scope

true

## Icon

receipt

## Information

- 講演会名、講師、支払額と根拠

# Activity 講演会案内の公開

## Scope

true

## Why

来場者へ講演会の内容を知らせる。

## When

広報担当が案内を公開するとき。

## Who

広報担当

## Where

資料館の広報媒体。

## How

### Input

- 講演会案内 — 講演会名、日時、説明文

### Procedure

1. 広報担当は公開内容を承認し、案内を公開する。

### Output

- 講演会案内 — 公開した内容

## Result

案内が公開される。

# Activity 講師謝礼の支払い確認

## Scope

true

## Why

講師謝礼の支払いに必要な証憑を確認する。

## When

会計担当が謝礼の支払いを確認するとき。

## Who

会計担当

## Where

資料館の会計業務。

## How

### Input

- 講師謝礼の証憑 — 講演会名、講師、支払額と根拠

### Procedure

1. 会計担当は証憑を確認する。

### Output

- 講師謝礼の証憑 — 確認結果

## Result

謝礼の支払いに必要な証憑の確認が終わる。
