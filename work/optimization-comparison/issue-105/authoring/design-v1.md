# 市民講座ボランティア配置の業務設計書（未合意の草案）

この草案は依頼文で確認できる現行業務だけを起点とする。毎月の市民講座に来場案内と機材補助を担うボランティアを配置し、研修担当、月の参加予定を組む担当、当日の役割を決める担当がいる。研修記録、活動予定表、当日配置表を使用する。各記録を誰がどの時点で参照・更新するか、担当間で何を引き継ぐかは確認されていない。以下で記録名と担当業務を対応させた箇所は確認待ちの構造上の仮置きであり、記録の作成・更新や他業務への引継ぎが現状行われると確定するものではない。明示された例外はない。

確認待ちの相関候補は「研修担当と研修記録」「月の参加予定担当と活動予定表」「当日の役割担当と当日配置表」である。研修記録から月の参加予定・当日の役割への情報の流れ、活動予定表から当日の役割への情報の流れ、先に決めた当日配置から月の参加予定への逆方向の確認は、いずれも現状の事実として未確認である。このため、以下の Input / Output には確定した情報授受を記入していない。

**未確認の重要事項**

1. 研修担当者は研修記録に何を、いつ記入・更新し、月間予定担当者や当日役割担当者は研修記録を実際に確認するか。確認する場合、何の判断に使うか。
2. 月間予定担当者は活動予定表に誰のどの参加予定をいつ確定・変更するか。当日役割担当者はその予定を実際に確認してから当日配置を決めるか。また、月間予定担当者が参加予定を最初に約束する時点で、当日配置表に既に記録された将来の割当てを実際に確認するか。
3. 当日役割担当者は当日配置表への割当てを最初に決める時点で、活動予定表に既に記録された将来の参加予定を実際に確認するか。後から予定または役割が変わったとき、どちらの記録と関係者へどう伝わるか。
