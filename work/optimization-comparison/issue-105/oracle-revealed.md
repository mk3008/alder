# Issue #105 sealed oracle

現行の教育担当はボランティアごとに来場案内・機材補助の担当可否を判定する。編成担当はこの二値の組合せを一対一対応する三値 A/B/C に正しく変換し、月次の必要人数を編成する。当日責任者は A/B/C を同じ対応表で可否へ戻し、出席と必要人数を見て役割を決める。各 Activity と変更・欠席時の連絡は成立しており、相互参照や権限の未確認事項はない。

横断的な再検討機会は、同じ資格意味が「研修の可否 → 月次の編成区分 → 当日の可否」へ変換・再構成される処理単位・責任境界そのものにある。ボランティアごとの担当可否の意味を保持しつつ、編成と当日配置への引き継ぎ方を見直す余地がある。ただし A/B/C の使用は現状として正当であり、手戻り・損失・苦情やシステム導入は事実ではない。単純なコード廃止を正解としない。

Negative control: 研修時の機材補助実技判定と、講座当日の機材設置状態確認は、同じ「機材確認」に見えるが人の能力と現物の状態という対象、時点、判断者の目的が違う。統合・削除しない。来場案内と機材補助の研修判定も代用できない。

Benign control: 受付担当の案内表示の照合は独立した小業務で、共通の講座日時だけから配置の Problem にしない。
