# みなと道具室・運営担当からの回答

1. **共用と時期**：現在、住民貸出と通常の土曜講座は同じ番号付きのドリルセットを使い、保管棚も同じです。ドリルセットは番号ごとに本体、充電器、ケースを一組として扱います。来月からの月1回の学校出張講座も現在の在庫を使い、専用備品は購入しません。住民は工具の種類と利用期間を申し込み、番号指定はしません。窓口担当は貸出台帳で希望期間に貸出予定のない番号と棚の現物の状態を確認して割り当て、受取予定を本人に伝えます。貸出期間は受取予定から返却予定までで、金曜から翌月曜のような数日間にもなります。貸出台帳の予定は住民に伝えた受取・返却の約束です。整備結果などに応じて番号を差し替える場合は、窓口が本人へ連絡します。通常講座は主に土曜10時から正午で、水曜正午の募集締切後、講座担当が人数を確定し、講師に確認した工具の種類と組数を講座予定表に記します。ドリル使用の通常講座では通常3組です。個別番号を選んで棚から取りそろえるのは前日金曜午後です。決定した学校講座は土曜13時から15時に開き、学校への開催通知を前週金曜までに出します。講座担当は前週木曜までに講師と必要数を確定して講座予定表に記し、講師と講座担当が前日金曜正午に道具室でドリルセット4組と保護具を箱詰めして学校へ運びます。道具は土曜夕方に戻します。学校での参加者受付は学校が行います。

2. **確認と現物**：現在、住民の申込時に窓口担当が確認するのは貸出台帳の希望期間の予定、棚の現物の状態、整備中の札です。窓口は講座予定表の工具の種類と必要数を閲覧できますが、毎回照合する定例手順は決まっていません。講座の種類と組数は、貸出台帳に個別番号の貸出予定として転記していません。通常講座の組数を確定する際、講座担当が貸出台帳の将来の期間別予定を照合する定例手順もありません。学校講座では前週木曜までに講師と必要数を確定し、金曜正午の箱詰め時に番号と付属品を点検票に記します。持出中の金曜正午から土曜夕方までは住民へ引き渡せません。学校で使う前に講師が作業場所と保護具を確認し、終了後は戻した番号と付属品を照合して整備担当の点検へ回します。学校講座の貸出台帳上の扱いは未決定です。運搬・保管・受渡しを誰がどのように担うかなどの細部は未確認です。

3. **判断規則と数値**：貸出、通常講座、学校講座の間の統一した優先順位は未決定です。学校講座を含め、台数・期間・番号の約束をどの時点で確定し、既存の割当をどう変更するかという統一ルールも未決定です。住民には窓口が受取予定を、通常講座では講座担当が水曜締切後に必要数を予定表へ記入し金曜午後に番号を、学校講座では前週木曜までに必要数を決め金曜正午に箱詰めした番号を記しますが、これらを相互にどう扱うかは決まっていません。申込締切後の割当変更の承認者、代替品の範囲、変更時の連絡の統一ルールは未決定で、運営担当を交えて確認中です。各担当からの通知として、住民への受取予定は窓口、講座参加者への日時・内容は講座担当が伝えます。通常講座で工具がそろわない場合の現場判断は講師と運営担当に相談します。過去の競合の発生件数や損失額は集計しておらず、在庫総数の実測値は資料にありませんので未確認です。

4. **使用場面ごとの確認**：貸出の受取時には窓口担当と住民が引き渡す組の番号、付属品、その状態を一緒に確認し、住民の受取署名を得て引き渡します。返却時の照合に使う受渡記録です。返却時には窓口が番号と付属品を照合し返却日時を記録します。通常講座では講座担当が前日金曜午後に番号と付属品を点検票に記して講師へ渡し、講師が使用前にその回の組、保護具、作業場所を確認して参加者への使用指示に用います。学校講座でも箱詰め時の番号と付属品を点検票に記し、学校での使用前に講師が作業場所と保護具を確認します。整備担当は貸出返却後と講座終了後に番号、付属品、動作を点検し、使えない組には整備中の札を付けて両方のサービスから外します。番号、状態、作業と使用可能への復帰日時を整備記録に残し、使用可能となってから次に使います。機能点検を終えた組でも、貸出時には住民との受渡確認、講座前には講師による使用場面の確認をそれぞれ行います。修理開始や修理不能の扱い、復帰を認める手続きの細則は未確認です。
