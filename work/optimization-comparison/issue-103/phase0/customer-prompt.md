# Synthetic customer への事実確認

`work/structural-discovery/issue-99/design/v4.md` は合意済み文書ではない。比較入力を作るため、現在の業務で確認できる事実、来月から始めることが決まった学校講座、まだ決まっていない規則、資料にない詳細を区別して答えてください。改善案や共通の解を提案する依頼ではありません。

1. 住民貸出、通常の土曜講座、予定された学校出張講座は同じ番号付きドリルセットを使うか。住民への貸出期間・番号の割当と通知、通常講座の水曜の必要数記入・金曜の番号選定、学校講座の前週通知・金曜正午の4組箱詰めから土曜夕方の戻りについて、現行と決定した将来を分けて確認してください。
2. 住民貸出の割当時に窓口は講座予定表を定例照合するか。通常講座の必要数を決めるとき講座担当は将来の貸出台帳を定例照合するか。学校講座の必要数決定、箱詰めから戻りまでの現物の扱いで確認できることは何か。閲覧可能と定例使用を区別してください。
3. 貸出・通常講座・学校講座の優先順位、台数・期間・番号の約束を確定する時点、割当変更の承認と通知の統一ルールは決まっているか。決まっていないものを明確にしてください。過去の競合件数、損失、在庫総数の実測がなければ、そのまま述べてください。
4. 住民への受渡時の番号・付属品確認と署名、講師の講座前の使用セット・保護具・作業場所確認、整備担当の機能点検と使用可能への復帰は、それぞれ現行の誰がいつ何のために行うか。似て見えても目的が異なる場合はその事実を確認してください。

記載のない詳細は「未確認」、判断待ちは「未決定」と答えてください。今後の予約方式、単一台帳、優先規則、中央管理者、システム導入を決めないでください。
