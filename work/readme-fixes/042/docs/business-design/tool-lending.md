# 地域住民への工具貸出・返却 業務設計書（草案・未確認事項あり）

提示されたヒアリング結果をもとにした草案です。業務上の合意・承認はまだ得ていません。

「貸出・返却の確認情報」は、提示された貸出・返却の記録と受渡しの署名をまとめて指す業務情報のまとまりです。新しい帳票の作成や、署名を同じ記録内に保管することを定めるものではありません。「貸出担当」「窓口担当」は説明のための役割名です。

未確認事項：
- 工具の返却確認：現物の番号や付属品が記録と一致しない場合の受領の扱い、次の対応、判断する担当は未確認です。この草案では例外時の扱いを定めていません。
- 工具の貸出：貸出・受渡し確認を行う担当と、署名する人は未確認です。「貸出担当」は仮称です。
- 返却後の引継ぎ：整備担当が点検待ちの組をどう把握し、どの情報を受け取るかは未確認です。通知や記録の引継ぎを実施しているとは記載していません。
- 後で補える事項：貸出の具体的な開始契機・場所、署名の保管先はヒアリングに記載がありません。点検の手順・完了条件・点検後の扱いは今回の記述範囲外です。

# Scope

団体が所有する工具と付属品を登録済みの地域住民へ貸し出し、返却時に窓口で現物と貸出時の記録を照合して、返却の受領を確認するまでを扱います。返却された組が整備担当の点検を待つ状態までを記載します。住民の登録業務と、整備担当による点検以降の作業は記述範囲に含めません。

# Activity 工具の貸出

## Scope

true

## Why

団体が所有する工具を登録済みの地域住民に貸し出す。

## When

登録済みの地域住民への貸出を行うとき。具体的な開始契機は未確認。

## Who

貸出担当（仮称・担当未確認）

## Where

未確認。貸出の受渡し場所はヒアリングに記載がない。

## How

### Input

- 工具と付属品 — 貸し出す工具番号と付属品
- 貸出・返却の確認情報 — 受渡しの署名と引渡しの記録

### Procedure

1. 貸出担当は、団体が所有する工具と付属品を登録済みの地域住民に貸し出す。
2. 貸し出した工具番号、付属品一覧、引渡しの記録を、貸出・返却の確認情報のうち貸出・返却の記録に残す。
3. 貸出・返却の確認情報のうち署名と引渡しの記録で、貸出の受渡しを確認する。署名をする人は未確認であり、この草案では割り当てていない。

### Output

- 貸出・返却の確認情報 — 貸し出した工具番号、付属品一覧、引渡しの記録

## Result

貸出の受渡しが署名と引渡しの記録で確認され、貸し出した工具番号と付属品一覧が返却時の照合に使える。

# Activity 工具の返却確認

## Scope

true

## Why

貸出時の記録と現物を照合し、返却の受領を確認する。

## When

工具と付属品が返却されたとき。

## Who

窓口担当

## Where

返却窓口

## How

### Input

- 工具と付属品 — 返却された現物の工具番号と付属品
- 貸出・返却の確認情報 — 貸し出した工具番号と付属品一覧

### Procedure

1. 窓口担当は、返却された工具と付属品の現物の番号・付属品を、貸出・返却の確認情報にある貸出時の工具番号・付属品一覧と照合する。
2. 照合結果と返却日時を、貸出・返却の確認情報のうち貸出・返却の記録に残す。
3. 照合と返却日時の記録で、返却の受領を確認する。

### Output

- 貸出・返却の確認情報 — 照合結果と返却日時

## Result

照合結果と返却日時が記録され、返却の受領が確認されている。返却された組は整備担当の点検を待つ。
