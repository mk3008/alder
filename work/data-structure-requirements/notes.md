# 備品購入申請のヒアリングメモ（比較試験用）

これは合意済みの仕様ではなく、担当者から聞いた内容である。

- 社員は一回の購入申請に複数の備品をまとめられる。各備品には数量を指定する。申請は申請番号で呼ぶ。
- 社員は配送と店頭受取を選ぶ。配送するときは届け先が必要で、店頭受取では届け先を入力しない。
- 承認者は申請を確認して承認または却下する。承認後、購買担当者が購入する。申請内の一部の備品だけを承認できるかは聞いていない。
- カタログの表示価格は後日変わる。購入後、経理担当者はその購入の金額を後から確認する。申請時の希望価格と実際の購入価格をどう扱うかは聞いていない。
- 申請番号は同じ部署内では重複しないが、異なる部署では同じ番号を使える。社員は部署を異動することがある。異動した社員の過去の申請をどう識別・表示するかは聞いていない。
- 備品の一部だけが品切れだった場合に、申請全体をどう扱うかは聞いていない。
