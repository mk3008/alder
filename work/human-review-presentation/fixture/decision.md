# 研究ケースの確定条件

このケースではBD-01の参加者上限を10から20へ変更する業務判断が完了したものと仮定する。実ユーザーの承認を表すものではない。BD-02とBD-03は変更しない。Check / Test / Code / traceは旧版のまま残した、意図的な同期漏れである。

`cancel(occupied)` の戻り値はキャンセル後の occupied 状態を表す。Falseは空室、Trueは使用中を意味する。成功可否のbooleanではない。この戻り値契約は研究fixtureの解釈を固定するための技術条件であり、BD-02の業務保証を変更しない。

Scopeはメモリ上の関数と単体テストまで。永続化・同時実行・本番認証・本番運用は検証していない。省略した機能を実装欠陥として追加要求しない。Checkの人間レビュー状態・新BDとの照合は今回の研究前提として未完了であり、テスト成功によって確認済みにしない。
