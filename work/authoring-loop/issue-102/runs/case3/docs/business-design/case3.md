# 備品貸出記録の業務設計（草案・確認待ち）

ヒアリングメモに基づく草案。以下の「未確認事項」は合意済みの運用ではない。貸出予定・現物の管理主体、記録媒体と貸出時の記録内容は未確認であり、各 Object の Scope は確認後に見直す。

**未確認事項（草案の前提として採用しない）**

1. **貸出可否確認と引渡し／貸出予定・返却記録**：貸出時にも予定または記録を更新しますか。ほかの備品担当による貸出との重複を避けるため、いつ誰が貸出確定を共有・確認しますか。貸出予定の管理主体も未確認です。
2. **貸出可否確認と引渡し／職員**：返却日はどのように決めますか。利用日に空きがない場合、職員には誰が何を伝えますか。
3. **故障連絡／プロジェクター現物**：故障はどの場面で、誰が判定しますか。整備後に次の貸出を再開できると誰が判断し、貸出予定や関係する職員へどう反映しますか。返却時に番号や付属品が合わない場合の扱いも未確認です。
4. **記録の媒体**：返却記録や貸出予定を紙と表計算のどちらで扱うかは未決定です。媒体が決まるまで、この草案は運用手段を指定しません。

# Scope

登録済みの職員による会議用プロジェクターの借用申出から、備品担当による引渡し、返却照合・記録、故障時の整備担当への連絡まで。整備作業自体は対象外。

# Activity 貸出可否確認と引渡し

## Scope

true

## Why

利用日に使用可能なプロジェクターを職員へ貸し出すため。

## When

登録済みの職員が会議用プロジェクターの借用を申し出て、利用日を伝えたとき。

## Who

備品担当

## Where

規定なし。

## How

### Input

- 職員 — 借用の申出と利用日
- 貸出予定 — 利用日の貸出予定
- プロジェクター現物 — 備品番号と使用可能状態

### Procedure

1. 備品担当は職員から借用の申出と利用日を受ける。
2. 備品担当は貸出予定でその日の予定を、プロジェクター現物で使用可能状態と備品番号を確認する。
3. 空いていて使用可能なプロジェクターの備品番号と返却日を職員に伝え、現物を引き渡す。

### Exception

- 現物が故障している場合、そのプロジェクターの次の貸出は行わず、故障連絡へ移る。空きがない場合の応答や扱いは未確認。

### Output

- 職員 — 備品番号と返却日、プロジェクターの引渡し

## Result

職員にプロジェクターが引き渡され、返却日が伝わっている。返却日に返却照合・記録を行える。

# Activity 返却照合・記録

## Scope

true

## Why

返却されたプロジェクターの番号と付属品を確認し、返却を記録するため。

## When

職員が返却日に備品担当へプロジェクターを返したとき。

## Who

備品担当

## Where

規定なし。

## How

### Input

- 職員 — 返却したプロジェクターと付属品
- プロジェクター現物 — 備品番号と付属品

### Procedure

1. 備品担当は職員からプロジェクターと付属品を受け取る。
2. 備品担当は現物の備品番号と付属品を照合し、返却記録に返却を記録する。

### Output

- 返却記録 — 返却した事実

## Result

番号と付属品が照合され、返却が記録されている。

# Activity 故障連絡

## Scope

true

## Why

故障したプロジェクターの次の貸出を止め、整備担当へ知らせるため。

## When

プロジェクターの故障が分かったとき。

## Exception When

- 貸出可否確認と引渡し — 使用可能状態の確認で故障が分かったとき

## Who

備品担当

## Where

規定なし。

## How

### Input

- プロジェクター現物 — 故障している状態と備品番号

### Procedure

1. 備品担当は故障したプロジェクターの次の貸出を行わず、整備担当へ故障を連絡する。

### Output

- 整備担当 — プロジェクターの故障の連絡

## Result

故障したプロジェクターの次の貸出は行われず、整備担当へ故障が伝わっている。以後の整備・貸出再開は未確認。
