会議室予約の[Alder業務設計書の草案](docs/business-design/case4.md)を作成しました。ヒアリングメモと `AGENTS.md` を基に、重複予約は成立しないこと、予約者本人は事前に取り消せることを記述しています。草案全体は確認待ちです。

運営担当に、次の3点を確認したいです。

1. 「事前の取消」に利用当日も含めますか。含めない場合、いつまで取消できますか。
2. 取り消した時間帯は、いつから再び予約可能にしますか。
3. 管理者は本人以外による取消や通常の期限を超えた取消を例外として認められますか。認める場合、どの条件で誰が判断しますか。

重複時の案内方法と取消結果の通知も未確定として草案に残しました。これらを含む業務上の判断が確認されるまで、草案を合意済みとは扱いません。使用資料はヒアリングメモと `AGENTS.md`、Alderの著述指針です。Alder plugin 0.2.2、著述指針の固定リビジョン `af733229c7f20c5a9fc1c4f094a8fb8c548fe544`。
