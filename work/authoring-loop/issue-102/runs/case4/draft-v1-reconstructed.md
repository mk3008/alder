# 会議室予約 業務設計書（草案・未確認）

対象は、社員による会議室の予約と予約者本人による事前の取消である。運営担当が判断中の取消条件と例外の扱いは末尾に残す。本書全体は依頼者の確認待ちである。

## Activity: 会議室を予約する

### Scope

true

### Why

社員が会議室を利用する日時を確保するため。

### When

社員が会議室を予約するとき。

### Who

社員

### Where

規定なし

### How

- Input: 空き状況から空いている会議室と日時、社員から選んだ会議室と日時。
- Procedure: 社員は空き状況から空いている会議室と日時を選ぶ。選んだ時間が既存の予約と重複しない場合、選んだ会議室と日時の予約を成立させ、予約結果を受け取る。
- Exception: 予約時間が重複する場合は予約できず、予約は成立しない。この場合の社員への伝え方と、その後の選び直しは未確認。
- Output: 予約記録に成立した予約、社員に予約結果。

### Result

重複しない会議室と日時の予約が成立し、社員が予約結果を受け取る。成立した予約は予約者本人による事前取消の対象になる。

## Activity: 自分の予約を取り消す

### Scope

true

### Why

予約者本人が事前に予約を取り消すため。

### When

予約者本人が、成立した自分の予約を事前に取り消すとき。「事前」に当日を含むかは未確認。

### Who

予約者本人

### Where

規定なし

### How

- Input: 予約記録から本人の予約、予約者本人から取消の意思。
- Procedure: 予約者本人は予約記録にある自分の予約について、事前に取消を行う。予約記録に取消を反映する。
- Output: 予約記録に取り消した予約。

### Result

予約者本人の事前取消が成立する。取り消した時間帯がいつ再び予約可能になるかは未確認。

## Object: 空き状況

### Scope

true

### Information

空いている会議室と日時。予約や取消が空き状況に反映される具体的な時点は未確認。

## Object: 予約記録

### Scope

true

### Information

予約者、会議室、日時、予約の成立と取消。記録の具体的な形式は未規定。

## Object: 社員

### Scope

false

予約を行い、予約結果を受け取る相手。予約者本人として取消の意思を示す。

## 未確定の業務判断（運営担当に確認）

1. **取消の許容期間（自分の予約を取り消す・When）**: 「事前」に利用当日を含めるか。当日取消を認めない場合、どの時点まで可能か。取消が成立する条件が変わる。
2. **取消後の再予約（自分の予約を取り消す・Result／空き状況）**: 取り消した時間帯をいつ空き状況へ反映し、別の社員が予約できるようにするか。取消後の予約可能性と両Activityの関係が変わる。
3. **管理者の例外（自分の予約を取り消す・Who／条件）**: 管理者が本人以外による取消や通常の期限を超えた取消を認められるか。認める場合、対象と判断権限を定める必要がある。現在は管理者による取消を確定した手順に含めていない。
4. **重複時の案内（会議室を予約する・Exception）**: 予約できない結果を社員へどう伝え、選び直しにつなぐか。重複不可の規則自体は確定している。
5. **取消結果の通知（自分の予約を取り消す・Output）**: 予約者本人が取消結果を受け取るか。メモには通知の有無がないため、現時点では手順に含めていない。
