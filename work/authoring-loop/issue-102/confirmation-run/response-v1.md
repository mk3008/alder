地域センターのカメラ貸出・撮影講習について、[業務設計書の草案](docs/business-design/camera.md)を作成しました。資料はヒアリングメモと作業場所の AGENTS.md です。まだ依頼者の確認前です。

確認したい点は次の3つです。

1. 窓口担当が貸す番号を決める時点で、講習予定表に記された土曜の必要台数を、将来の利用分として**実際に照合していますか**。
2. 講習担当が木曜夕方までに必要台数を記す時点で、貸出台帳にある金曜から日曜の貸出予定を、将来の利用分として**実際に照合していますか**。金曜午後の番号選びで見るかどうかも教えてください。
3. 8台で足りない場合の優先順位と調整・連絡の担当は、どのように決めますか。「まだ未決定」のままでも構いません。

番号と受取時刻の記録先、後から番号が変わる際の連絡方法も草案内に未確定として残しました。回答を受けた部分から既存草案を更新します。
