# 地域センターのカメラ貸出・撮影講習 業務設計書（確認待ち草案）

本書はヒアリングメモから分かる業務だけを記した草案であり、依頼者による確認前である。

## 対象

地域センターの番号付きカメラ8台について、登録者への金曜から日曜までの貸出と、土曜の撮影講習での利用を扱う。

## 未確定の業務判断（依頼者確認待ち）

1. **貸出番号を決める時点**：窓口担当が貸出申込時に講習予定表の必要台数を、将来の利用の約束として実際に照合するかは未決定。閲覧できることだけから照合を通常手順とはしない。
2. **台数不足が判明したとき**：貸出と講習の優先順位、調整担当は未決定。どちらかを満たせない場合の調整結果や伝達先・伝達内容も確定していない。
3. **講習の具体番号を選ぶ時点**：講習担当が金曜午後に貸出台帳の貸出予定を確認するかは未確認。木曜までの必要台数決定時には貸出台帳を定例確認していないという回答から、金曜の手順までは推定しない。
4. **番号決定後の引継ぎ**：貸出番号や受取時刻を貸出台帳へ記すか、講習用に選んだ具体番号を講習予定表などに記すか。また後から番号が変わるとき誰にどう伝えるか。現時点では記録や変更手順を確定しない。

## Object 登録者

### Scope

false

登録者は貸出を申し込み、受取時刻の連絡を受ける相手である。

### Information

- 金曜から日曜までの貸出申込
- 受取時刻の連絡

## Object 貸出台帳

### Scope

true

窓口担当が貸出番号の選択時に見る台帳。記録内容や更新方法は未確認。

## Object 講習予定表

### Scope

true

### Information

- 土曜の撮影講習の必要台数

## Object カメラの棚

### Scope

true

### Information

- 番号付きカメラ8台の現物

## Activity 講習の必要台数を記す

### Scope

true

### Why

土曜の撮影講習に必要なカメラの台数を示す。

### When

土曜の撮影講習に向けて、木曜の夕方までに必要台数を定めるとき。

### Who

講習担当

### Where

規定なし。

### How

#### Input

- なし（貸出台帳は閲覧できるが、この時点では定例確認していない）

#### Procedure

講習担当は、講習予定表に必要台数を木曜の夕方までに記す。この時点では貸出台帳を定例確認していない。

#### Output

- 講習予定表：土曜の撮影講習の必要台数

### Result

必要台数が講習予定表に記され、金曜午後の具体番号の選択に使える。

## Activity 貸すカメラの番号を決める

### Scope

true

### Why

登録者の金曜から日曜までの貸出に使うカメラを決める。

### When

登録者が窓口で金曜から日曜までの貸出を申し込むとき。

### Who

窓口担当

### Where

地域センターの窓口とカメラの棚。

### How

#### Input

- 登録者：金曜から日曜までの貸出申込
- 貸出台帳：貸出に関する台帳の情報
- カメラの棚：番号付きカメラの現物

#### Procedure

窓口担当は登録者から窓口で申込を受ける。貸出台帳とカメラの棚の現物を見て貸す番号を決め、登録者に受取時刻を伝える。

#### Output

- 登録者：受取時刻

### Result

貸すカメラの番号が決まり、登録者に受取時刻が伝わる。

## Activity 講習で使うカメラの番号を選ぶ

### Scope

true

### Why

土曜の撮影講習で使うカメラの具体番号を選ぶ。

### When

必要台数が講習予定表に記され、金曜の午後になったとき。

### Who

講習担当

### Where

地域センターのカメラの棚。

### How

#### Input

- 講習予定表：撮影講習の必要台数
- カメラの棚：番号付きカメラの現物

#### Procedure

講習担当は金曜の午後に、講習予定表の必要台数を踏まえ、カメラの棚から具体番号を選ぶ。

#### Output

- なし（具体番号の記録先・引継ぎ先は未確認）

### Result

講習担当が土曜の撮影講習で使うカメラの具体番号を選んだ状態になる。
