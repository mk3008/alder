地域センターのカメラ貸出・撮影講習について、[業務設計書の草案](docs/business-design/camera.md)を作成しました。ヒアリングメモと指定の `AGENTS.md` を基に、窓口の貸出番号決定、講習の必要台数記入、金曜午後の講習用番号選定を記述しています。まだ合意済みの設計ではありません。

確認したい点は次の3つです。

1. 窓口担当は貸す番号を決める際、講習予定表の必要台数や講習側の先行した約束を通常確認しますか。確認するなら、講習用の台数・番号をいつ確保した扱いにしますか。
2. 講習担当は金曜午後に番号を選ぶ際、貸出台帳で先行する貸出の約束を通常確認しますか。既に貸すと決めた番号はどう扱いますか。
3. 8台では足りない場合の優先順位と、不足・番号変更を誰が判断し、窓口担当・講習担当・登録者にどう知らせるかはどうしますか。まだ決められない場合は未決定のまま残します。

番号決定後の台帳・予定表への記録方法も未確認として草案に残しています。これらの確認が済むまで、貸出と講習の競合時の結果は確定できません。
