# 地域センターのカメラ貸出・撮影講習 業務設計書（初稿・未確認）

対象は、番号付きカメラ8台を用いる登録者への貸出と土曜の撮影講習について、必要台数の記載、番号の選定、登録者への受取時刻の連絡までとする。以下はヒアリングメモで確認できた業務だけを記す。競合時の扱いなどは未決であり、業務上の合意は得ていない。

## 対象となるものと情報

以下の Scope は、この設計で扱うセンター内の業務・資料を `true`、申し込む相手を `false` とした暫定的な境界であり、資料の管理者や台帳更新手順を確定するものではない。

### Object：登録者

Scope: `false`。金曜から日曜までの貸出を窓口で申し込み、受取時刻の連絡を受ける相手。

### Object：カメラと棚

Scope: `true`。地域センターにある番号付きカメラ8台と、その現物を確認する棚。

### Object：貸出台帳

Scope: `true`（暫定）。窓口担当が番号の選定時に見るもの。講習担当も閲覧できる。記載項目や更新の手順は未確認。

### Object：講習予定表

Scope: `true`。講習担当が土曜の撮影講習に必要な台数を木曜夕方までに記すもの。窓口担当も必要台数を閲覧できる。

## 活動：講習の必要台数を記す

- **Scope**：`true`。
- **Why**：土曜の撮影講習で使うカメラの必要台数を示す。
- **When**：土曜の撮影講習に向け、木曜の夕方まで。
- **Who**：講習担当。
- **Where**：規定なし。
- **Input**：撮影講習の必要台数。台数をどう決めるかは未確認。
- **Procedure**：講習担当は必要台数を講習予定表に記す。貸出台帳を閲覧できるが、この活動で照合するかは未確認。
- **Output**：講習予定表に記された必要台数。窓口担当が閲覧できる。
- **Result**：土曜の講習に必要な台数が講習予定表に示され、後の具体番号の選定で参照できる状態になる。必要台数の記載がカメラを確保する約束になるかは未確認。

## 活動：貸出の申し込みを受け、貸す番号を決める

- **Scope**：`true`。
- **Why**：登録者の貸出申込に対し、貸すカメラの番号を決める。
- **When**：登録者が金曜から日曜までの貸出を窓口で申し込むとき。申込日と各カメラの貸出・受取時刻の詳細は未確認。
- **Who**：窓口担当。
- **Where**：地域センターの窓口と、カメラ現物を確認する棚。
- **Input**：登録者の貸出申込、貸出台帳の情報、棚にあるカメラの現物。講習予定表の必要台数も閲覧可能だが、選定時に使うかは未確認。
- **Procedure**：窓口担当は貸出台帳と棚の現物を見て、貸すカメラの番号を決め、登録者に受取時刻を伝える。台帳への記録や実際の受渡しは未確認。
- **Output**：選定された貸出用カメラ番号と、登録者に伝えた受取時刻。
- **Result**：貸す番号が決まり、登録者は受取時刻を知らされる。講習分との競合をどの時点でどう扱うかは未確認。

## 活動：講習で使う具体番号を選ぶ

- **Scope**：`true`。
- **Why**：土曜の撮影講習で使うカメラを具体的に選ぶ。
- **When**：必要台数が講習予定表に記された後、金曜の午後。
- **Who**：講習担当。
- **Where**：カメラ現物を確認する棚。
- **Input**：講習予定表の必要台数と棚のカメラ。貸出台帳も閲覧可能だが、選定時に照合するかは未確認。
- **Procedure**：講習担当は棚から講習用カメラの具体番号を選ぶ。
- **Output**：講習用に選んだカメラの具体番号。その記録先や窓口担当への伝達は未確認。
- **Result**：講習で使う具体番号が選ばれる。先に決まった貸出番号と重なった場合の扱いは未確認。

## 未確認の業務判断（依頼者の確認待ち）

1. **講習の台数記載と貸出番号選定**：木曜夕方に必要台数を記す時点で、既に成立している貸出の約束を講習担当は確認し、必要台数に反映しますか。逆に窓口担当は、貸す番号を決める時点で講習予定表の必要台数を確認し、その台数を講習用の約束として扱いますか。各時点で約束される数量・時間帯と、8台に対する空きの判断が変わる。
2. **講習の具体番号選定**：金曜午後に講習担当が番号を選ぶ際、既に決めた貸出番号を確認して重複を避けますか。選定した番号はどこに記し、窓口担当や影響を受ける登録者にどう伝わりますか。具体番号の重複と連絡の責任が変わる。
3. **8台で足りない場合**：貸出と講習が競合する場合の優先順位は未決。どの約束を維持・変更し、誰が判断して誰に結果を伝えるかの決定が必要。現時点では通常手順の結果として確定しない。
4. **受取と貸出台帳**：伝える受取時刻と実際の受渡しの関係、および貸出台帳に誰がいつ何を記録するかは未確認。番号選定後の約束・現物管理の境界を確かめる必要がある。
