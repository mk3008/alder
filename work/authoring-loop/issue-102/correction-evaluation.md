# Issue #102 追加2ケースの判定

対象は Plugin 0.2.3 の Skill、`correction-protocol.md` で事前固定した case2/4。初回4件の `evaluation-raw.md` は変更しない。requested model `gpt-6-sol`、effort `medium`、`fork_turns: none`。各 Agent の自己申告の読み込み記録と raw 応答は `correction-runs/` に固定した。

| 基準 | 判定 | 観測 |
| --- | --- | --- |
| case2、共用備品の双方の将来約束を依頼者に実際に問う | **fail** | `response-v1.md` は窓口が講座予定表を見るかを尋ねたが、講座担当が水曜の必要数決定時に既存貸出予定を確認するかを尋ねなかった。草案にも講座側からの確認時点は明示的な問いとして残らない。関連質問の条件を満たさないため、事前条件どおり固定回答を渡していない。 |
| case4、初稿の取消後の空き可否 | **pass** | `response-v1.md` は「取り消された時間帯は再び予約可能になりますか」と可否を先に尋ね、草案は空きに戻すことを確定しない。 |
| case4、未決定回答後の停止 | **pass** | `response-v2.md` は追加回答を受領し、当日取消・取消後の空き・最終判断者を未決事項として維持すると伝える。直後に同じ問いを質問リストとして再掲しない。`diff-v1-v2.patch` と更新草案も未決を維持。 |

各ケースは1回のみ。case2 の回答後の改稿は条件未成立で未観測。case4 の固定回答は `protocol.md` に記録した文面。4件の初回評価からの一般的な改善率は測らない。case2 の失敗を受け、次の Skill 修正と検証を別に記録する。
