# 読み込み記録

- `notes.md`：会議室予約のヒアリングメモ全文。業務事実と未決事項の根拠。
- `AGENTS.md`：草案の配置先 `docs/business-design/case4.md`、未回答の判断を残す指示。
- `skills/alder-draft-business-design/SKILL.md`：起案と応答・追跡の手順全文。
- `skills/alder-draft-business-design/references/adoption.md`：第1節の冒頭から第2節見出しまで（著者向け指針）。
- `skills/alder-draft-business-design/references/business-graph.md`：任意のMarkdownプロファイルの最小例まで（今回は任意プロファイルを採用せず）。
- `skills/alder-draft-business-design/references/provenance.json`：固定資料のリビジョンとダイジェスト。

読み込み範囲はこの作業場所内のみ。既存の業務設計書はなかった。初稿は指定先に作成し、`draft-v1.md` に同じ内容を保存した。
