# 会議室予約 業務設計書（草案・未合意）

## 対象

社員による会議室の予約と予約者本人による事前取消を扱う。顧客は、当日の取消、取消後の空き扱い、最終判断者を現時点で決めていない。以下の未決事項は確定した運用条件ではない。

## 関係する情報

- 社員：会議室と日時を選び、予約結果を受け取る。予約者本人は事前取消を行える。
- 会議室の予約情報：会議室、予約日時、予約者、予約の結果、および取消の対象となる予約。予約成立後の状態と取消後の扱いを示す情報の詳細は未確認。

## Activity：会議室を予約する

- **Why:** 社員が希望する会議室と日時を予約する。
- **When:** 社員が会議室と日時を選び、予約を求めるとき。
- **Who:** 社員。
- **Where:** 規定なし。
- **Input:** 社員が選んだ会議室と日時、重複を判定するための予約情報。
- **Procedure:** 選んだ会議室と日時について予約時間の重複を確認する。重複がなければ予約し、社員に予約結果を渡す。
- **Exception:** 予約時間が重複する場合は予約できない。重複時に社員へ何を通知するかは未確認。
- **Output:** 成立した予約と社員が受け取る予約結果。
- **Result:** 重複のない予約が成立し、社員がその結果を受け取る。成立した予約は本人による事前取消の対象となる。

## Activity：予約を取り消す

- **Why:** 予約者本人が事前に予約を取り消す。
- **When:** 予約者本人が成立済みの予約について事前取消を求めるとき。当日を含むかは未確認。
- **Who:** 予約者本人。
- **Where:** 規定なし。
- **Input:** 取消対象の予約と予約者本人からの取消の意思。
- **Procedure:** 予約者本人の事前取消として対象予約を取り消す。
- **Output:** 取り消された予約。取消結果を誰に、どのように伝えるかは未確認。
- **Result:** 対象予約が取り消される。取り消した時間帯を空きとして扱うかどうか、および再予約可能にするかどうかは未決。

## 未決事項・未確認事項

1. **予約を取り消す／当日の条件（顧客回答：未決）:** 予約当日の取消を認めるかは未決。認める場合、いつまでを「事前」と扱うかも判断が必要。取消を受け付ける結果が変わる。
2. **予約を取り消す・会議室を予約する／取消した時間帯（顧客回答：未決）:** 取消後に部屋を再び空きとして扱うかは未決。空きとして扱う場合、再予約を可能にするか、いつから可能にするかも判断が必要。取消の結果と次の予約の受付条件が変わる。
3. **予約を取り消す・会議室を予約する／最終判断者と管理者の例外（顧客回答：最終判断者は未決）:** これらの運用条件を誰が最終判断するかは未決。管理者に例外を認める権限を与えるか、与える場合の対象条件、判断者、予約や取消の結果も未確認。責任と例外条件が変わる。
4. **会議室を予約する／重複時の伝達:** 予約できなかった場合に社員へ伝える結果の内容は何か。社員への情報引き渡しが変わる。
5. **予約を取り消す／取消結果の伝達:** 取消結果を予約者本人に伝えるか。伝える場合、どの内容を結果として渡すか。取消後の情報引き渡しが変わる。
