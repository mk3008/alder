# コーディネーター指摘への限定的な再判定

初回原本は `evaluation/original/` に保存したまま変更していない。発言録、公開0.4.4のadoption第1節・structure、凍結rawに限定して6点を照合した。以下は要件文言が残ることと、BD内で未合意の仕事・担当・記録先を確定することを分けた判定である。

1. **採用：記録保全Activityの責任付与。** T052は復元の依頼者を未決とし、T068・T070は連絡先を消す条件を決めるが実行者を指定しない。草案767–814行のActivityはScope=true、Who=受付（771、783行）で、同じProcedure内に保持、消去、離席後の保護、復元が並ぶ（800–804行）。Whoは仕事の担当を示すため（公開adoption 78、104行）、条件の文字面を保持していても、受付がこれらの横断処理を行うと読む余地を確定的に作る。復元の依頼者未決との内部緊張もある。ただし「受付が復元を依頼する」と明記はしていないので、実行者決定を断言するより、**未根拠の責任帰属を示唆する意味変更**とする。R033、R044、R058、R059の台帳に同じ根本欠陥として注記し、欠陥数は1件。

2. **一部採用：道具評価の仕事は許せるが、担当・転記先は未根拠。** T072は実際の店の人による使いやすさ確認、T076は費用と営業時間条件を見て方法を比較することを述べる。したがって草案816–861行のように評価を整理することや、3秒・8人・月99.5％・片手操作をBDに残すこと自体は不備ではない。だがScope=trueのActivityでWho=受付と固定する832行は、店の人全体から受付単独の責任へ狭める。855–857行の予約表・在庫表・貸出票への評価条件Outputは、業務台帳が要件受入結果を受け取るという発言にないデータ移送を創作する。公開adoption 80、85行はOutputを実際の受渡情報とする。R009、R039、R041、R042、R062の台帳に同一根本欠陥として付記し、欠陥数は1件。数値目標そのもののロストや採用済み技術選択とはしない。

3. **採用：準備結果の予約表Outputは未根拠。** T022は準備完了・未完了を17時までに受付へ伝える。T024は倉庫が準備結果を記入できることを求める。しかし、書く先が予約表とは特定しておらず、T006の予約表情報にも準備結果は挙がらない。草案242、246行の受付への連絡は適合する一方、251行の「予約表 — 受付が把握する準備結果・未準備の連絡」は連絡相手と保存Objectを同一視する。合理的な案として将来検討できても、確定したOutputとしては根拠不足。R017・R019に同じ不備として付記し、欠陥数は1件。準備の前営業日・17時条件自体は保持。

4. **採用：総括文を訂正。** 初回報告の「R030–R033…を保持」はR032のロスト判定と矛盾した。改訂報告ではR030–R031、R033とし、R032を独立に記す。

5. **採用：R032全ロストを部分保持へ緩和。** T040の「サインインの方式」未決は固有名で再掲されていない。しかし草案13行は一般に「本人確認の方法…未決」と書き、初期サインインも含む解釈を排除できない。803行は明確に5分無操作後の再開だけを指す。両箇所を合わせても対象範囲が曖昧なので完全保持とも断定せず、**partial／unconfirmed、中程度の確信**とした。特定方式の採用という誤変更はない。初回のlost／absentは狭すぎた。曖昧な対応のため確定欠陥数には算入しない。

6. **採用：相互照合質問の一部は反復。** T010は新規確定時に期間の重なる確定予約の台数を予約表で確認する。T056は延長時に予約表の後の予定を見て、予約表と貸出票の両方を直す。よって草案7行の「新規が記録済み延長予定を確認するか」「延長が確定予約を実際に確認するか」は、通常の言葉の意味では既に述べられた確認を再質問している可能性が高い。相手の既存確約を無視してよいかという未決を新設しない。一方、T010は予約済み実機の準備割当と稼働台数の関係を説明せず、T056も準備済みの次の貸出しへの影響処理を詳述しない。草案7行後段・8行の実例照合は新しい実務確認として妥当。質問の冗長さは台帳の保持失敗や独立した重大欠陥には数えない。

改訂台帳の要件行数は66のまま。保持63、部分保持2、ロスト0、not_applicable1。独立欠陥はR002対象顧客の部分欠落、R034日次紙控えのWhen接続、上記1〜3の未根拠な役割・Outputの計5件。R032は明確さ不足の留保とし、欠陥数に含めない。重複する台帳注記は根本欠陥ごとに統合した。
