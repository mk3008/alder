# Case S01: 荷札の印刷条件

## 前提

これは架空の現行業務である。出荷担当者は荷札の部数を変更したいときに設定画面を開く。部数は出荷担当者が決めてよく、承認は不要である。この仕事では部数を保存するだけで、荷札は印刷しない。保存済みの部数を使った印刷は、後で荷物の仕分けが完了したときに印刷サービスが行う。今回の変更値は入力可能な範囲内で、保存も正常に成功する。

# Scope

出荷担当者による荷札の印刷部数の設定と、設定台帳の管理を扱う。仕分けと荷札の実印刷は対象外とする。

false

## Icon

## Information

- 希望する印刷部数

# Object 印刷設定台帳

## Scope

true

## Icon

(generic icon)

## Information

- 保存済みの印刷部数

# Activity 仕分け完了時に荷札の印刷部数を設定する

## Scope

true

## Why

後で印刷する荷札の部数を、出荷担当者が必要とする数にそろえる。

## When

出荷担当者が荷札の部数を変更したいと考えたとき。

## Who

出荷担当者

## Where

荷札の設定画面。

## How

### Input

- 部数変更案 — 希望する印刷部数
- 印刷設定台帳 — 保存済みの印刷部数

### Procedure

1. 希望する印刷部数と保存済みの印刷部数を見比べる。
2. 希望する印刷部数を設定画面へ入力し、保存する。
3. 保存後の部数を設定台帳から読み出して画面で確認する。

### Output

- 印刷設定台帳 — 変更後の印刷部数

## Result

希望する部数が保存され、後続の印刷サービスがその部数を参照できる。

# Case S05: 開館時の照明

## 前提

これは架空の現行業務である。施設担当者は開館時に使う照明の明るさを事前に決め、入力欄へ設定案を用意する。開館時と閉館時の照明設定は別々に保存され、この設計では開館時の設定だけを扱う。この設計の対象は、用意された案に対して保存操作をする場面から始まる。開館まで待たずに保存できる。保存中に照明を点灯することはない。施設担当者が設定を決めてよく、別の承認は不要である。このケースの値は登録可能で、保存は正常に成功する。

# Scope

入力済みの照明設定案の保存と照明設定台帳の管理を扱う。設定案を考える仕事と開館時の実際の点灯は対象外とする。

# Object 入力済み照明設定案

## Scope

false

## Icon

(generic icon)

## Information

- 対象の照明
- 希望する明るさ

# Object 照明設定台帳

## Scope

true

## Icon

(generic icon)

## Information

- 対象の照明
- 保存済みの明るさ

# Activity 開館時の照明設定を保存する

## Scope

true

## Why

開館時の点灯で参照する明るさを、施設担当者が決めた値に更新する。

## When

施設担当者が入力済みの照明設定案に対して保存操作を開始したとき。

## Who

施設担当者

## Where

施設管理端末の照明設定画面。

## How

### Input

- 入力済み照明設定案 — 対象の照明 / 希望する明るさ

### Procedure

1. 入力済みの対象照明と明るさを保存する。
2. 保存後の内容を照明設定台帳から画面へ読み出し、入力した値と一致することを確認する。

### Output

- 照明設定台帳 — 対象の照明の保存済みの明るさ

## Result

指定した明るさが台帳に保存され、開館時の点灯処理が参照できる。

# Case S02: 空容器の振り分け設定

## 前提

これは架空の現行業務である。容器管理担当者は、変更依頼を受け取った時点で回収容器の振り分け先を設定する。設定は入庫作業の前に済ませる。管理担当者は依頼された振り分け先をそのまま登録する責任を持ち、別の承認は不要である。回収容器が搬入口に到着すると搬送機が保存済み設定を使って振り分けるが、その到着によって設定作業を始めることはない。登録対象は存在し、保存は正常に成功する。

# Scope

容器の種類ごとの振り分け先設定と、振り分け設定台帳の管理を扱う。回収容器の入庫と搬送機による実際の振り分けは対象外とする。

## Scope

false

## Icon

(generic icon)

## Information

- 容器の種類
- 変更後の振り分け先

# Object 振り分け設定台帳

## Scope

true

## Icon

(generic icon)

## Information

- 容器の種類
- 保存済みの振り分け先

# Activity 回収容器の振り分け先を設定する

## Scope

true

## Why

次の入庫で、依頼された保管場所へ容器を振り分けられるようにする。

## When

回収容器が搬入口に到着したとき。

## Who

容器管理担当者

## Where

搬送機の設定端末。

## How

### Input

- 振り分け先変更依頼 — 容器の種類 / 変更後の振り分け先
- 振り分け設定台帳 — 対象の種類の保存済みの振り分け先

### Procedure

1. 依頼の容器の種類に対応する設定を開く。
2. 依頼された振り分け先に変更して保存する。
3. 台帳の保存済みの振り分け先が依頼内容と一致することを確認する。

### Output

- 振り分け設定台帳 — 対象の種類の変更後の振り分け先

## Result

対象の容器の振り分け先が保存され、後続の搬送機がその設定を参照できる。

# Case S06: 保存済みの座席図

## 前提

これは架空の現行業務である。施設担当者は保存済みの座席図を管理画面に表示して、別途用意した配置案と見比べる前の準備をする。この仕事の完了は、指定した座席図を画面で参照できることまでである。利用者による内容の理解や配置案との照合は、この仕事の完了条件に含めない。指定した座席図は存在し、表示に成功する。閲覧による台帳の更新や承認はない。

# Scope

保存済み座席図の閲覧と座席図表示の生成を扱う。座席図台帳の更新、配置案との照合、配置の承認は対象外とする。

false

## Information

- 対象の座席図

# Object 座席図台帳

## Scope

## Icon

## Information

- 保存済みの座席図

# Object 座席図表示

## Icon

(generic icon)

## Information

# Activity 保存済みの座席図を閲覧する

## Scope

true

## Why

施設担当者が、後の配置案との照合に使う座席図を参照できるようにする。

## When

施設担当者が閲覧希望の座席図を指定して開いたとき。

## Who

施設担当者

## Where

施設管理画面の座席図表示欄。

## How

### Input

- 閲覧希望 — 対象の座席図
- 座席図台帳 — 指定した保存済みの座席図

### Procedure

1. 閲覧希望で指定した座席図を台帳から開く。
2. 保存済みの座席図を表示欄へ表示し、閲覧できる状態にする。

### Output

- 座席図表示 — 指定した保存済みの座席図

## Result

指定した座席図が画面で参照でき、施設担当者は次の配置案との照合へ進める。
