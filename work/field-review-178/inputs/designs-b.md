# Case S03: 温室の散水時間

## 前提

これは架空の現行業務である。栽培担当者は散水時間の変更案を受け取ると、当日中に設定を保存する。案をそのまま保存してよく、別の承認は不要である。設定した散水は翌日の開始時刻に制御装置が実行する。設定画面で保存しても、その場では散水しない。散水が正常終了したかどうかは翌日の実行結果で分かる。今回の設定値は登録可能で、保存は正常に成功する。

# Scope

散水時間の設定と散水設定台帳の管理を扱う。散水の実行と実行結果の記録は対象外とする。

# Activity 温室の散水時間を設定する

## Scope

true

## Why

後続の制御装置が、栽培担当者から渡された時間どおりに散水を開始できるようにする。

## When

栽培担当者が散水時間の変更案を受け取ったとき。

## Who

栽培担当者

## Where

温室の設定画面。

## How

### Input

- 散水時間変更案 — 対象の温室 / 開始時刻 / 散水時間
- 散水設定台帳 — 対象の温室の保存済みの設定

### Procedure

1. 対象の温室の保存済みの設定を開く。
2. 変更案の開始時刻と散水時間を入力して保存する。
3. 保存後の設定が変更案と一致することを確認する。

### Output

- 散水設定台帳 — 対象の温室の変更後の開始時刻 / 散水時間

## Result

設定した時間の散水が完了している。

# Case S07: 清掃周期の草案

## 前提

これは架空の変更後業務の草案である。管理担当者は清掃周期案を登録する。登録する内容は対象区画と清掃の間隔であり、登録自体は現時点でも試せる。周期を変更した際、すでに作成済みの清掃予定まで組み直すかは、運用責任者がまだ決めていない。未決の間は設定を実運用へ適用せず、予定の再作成も行わない。担当者、登録の開始条件、保存内容については決まっている。試行用の区画と値は存在し、登録は正常に成功する。

# Scope

試行用の清掃周期案の登録と清掃周期台帳の管理を扱う。実運用への適用と清掃予定の生成・再作成は対象外とする。既存予定への適用方針は未決として保持する。

## Scope

false

## Icon

## Information

- 対象区画
- 清掃の間隔

# Object 清掃周期台帳

## Scope

true

## Icon

(generic icon)

## Information

# Activity 清掃周期案を登録する

## Scope

true

## Why

運用方針の検討に使う清掃周期案を、試行用として保持する。

## When

管理担当者が清掃周期案を受け取ったとき。

## Who

管理担当者

## Where

試行用の清掃管理画面。

## How

### Input

- 清掃周期案 — 対象区画 / 清掃の間隔

### Procedure

1. 受け取った区画と間隔を、試行用の設定として登録する。
2. 保存された値と試行用の表示を確認する。実運用には適用しない。

### Output

- 清掃周期台帳 — 対象区画 / 保存済みの清掃の間隔 / 試行用であること

## Result

清掃周期案が試行用として保存され、運用責任者が方針の検討時に参照できる。既存予定への適用方針は未決のままである。

# Case S04: 貸出用具の引き渡し

## 前提

これは架空の現行業務である。貸出希望は備品窓口で受け付ける。貸出担当者は利用可能な用具を利用申込者へ引き渡す責任を持つ。備品窓口は引き渡し場所の名前であり、担当ロールの名前ではない。確認と引き渡しは、申込者が受け取りに来るまでの待ち時間を挟むため、別の仕事として扱う。このケースでは対象用具は利用可能で、申込者も受け取りに来る。外部での本人確認や承認は必要ない。

# Scope

利用可能な貸出用具の確認、受け取り時の引き渡し、用具台帳と受付票の管理を扱う。利用後の返却は対象外とする。

# Activity 貸出用具の空きを確認する

## Scope

true

## Why

希望する用具を引き渡せるか確かめる。

## When

利用申込者から貸出希望を受け取ったとき。

## Result

対象用具を引き渡せることが確認され、申込者が受け取りに来たときに受付票を使って引き渡せる。

# Activity 貸出用具を引き渡す

## Scope

true

## Why

利用申込者が希望する用具を使えるようにする。

## When

利用可能と記録された受付票があり、利用申込者が受け取りを申し出たとき。

## Who

備品窓口

## Where

貸出担当者。

## How

### Input

- 利用申込者 — 受け取りの申し出
- 受付票 — 対象用具 / 利用可能の確認結果
- 用具台帳 — 対象用具の貸出状態

### Procedure

1. 貸出担当者は受付票の対象用具と受け取りの申し出を照合する。
2. 貸出担当者は用具台帳で利用可能な状態を再確認し、対象用具を申込者に渡す。
3. 貸出担当者は台帳を貸出中にし、受付票へ引き渡し済みと記録する。

### Output

- 利用申込者 — 対象用具
- 用具台帳 — 対象用具の貸出中の状態
- 受付票 — 引き渡し済みの状態

## Result

申込者が対象用具を受け取り、台帳と受付票にも引き渡しが反映されている。申込者は用具の利用へ進める。

# Case S08: 開場時の案内曲

## 前提

これは架空の現行業務である。音響担当者は、開場時に一度流す案内曲を開場前に登録する。開場時と休憩時の案内曲は別々に登録でき、この設計では開場時の案内曲だけを扱う。曲の登録と再生は別の仕事であり、登録だけでは曲は流れない。開場信号を受けた再生サービスが、保存済みの曲を一度流す。登録する曲は選曲案で指定されており、音響担当者がそのまま登録してよい。指定の音源は利用可能で、保存と再生は正常に成功する。繰り返し再生や聞き手の理解確認は行わない。

# Scope

案内曲の登録、開場信号に応じた一回の再生、再生設定と再生履歴と会場音響出力の管理を扱う。選曲案の作成、開場信号の発生、音源の管理は対象外とする。

# Activity 開場時の案内曲を登録する

## Scope

true

## Why

開場時に流す曲を、選曲案で指定された曲にそろえる。

## When

音響担当者が選曲案を受け取ったとき。

## Who

音響担当者

## Where

音響管理端末の設定画面。

## How

### Input

- 選曲案 — 案内曲
- 音源 — 指定された案内曲の音声

### Procedure

1. 選曲案の案内曲が音源にあることを確認する。
2. 案内曲を再生設定へ登録し、保存された曲が選曲案と一致することを確認する。

### Output

- 再生設定 — 保存済みの案内曲

## Result

案内曲が設定として保存され、再生サービスが開場時に参照できる。

# Activity 開場時の案内曲を再生する

## Scope

true

## Why

今回の開場に合わせて、設定された案内曲を会場へ流す。

## When

案内曲が登録済みで、今回の開場信号を受け取ったとき。

## Who

再生サービス

## Where

会場の音響設備。

## How

### Input

- 開場信号 — 今回の開場の合図
- 再生設定 — 保存済みの案内曲
- 音源 — 設定された案内曲の音声

### Procedure

1. 今回の開場信号を受け、設定された案内曲を音源から読み込む。
2. 会場の音響設備へ音声を出力して、一度再生する。
3. 再生が終わったことを検知し、今回再生した曲と終了状態を履歴へ記録する。

### Output

- 会場音響出力 — 今回の案内曲の音声
- 再生履歴 — 今回再生した案内曲 / 再生の終了状態

## Result

今回の案内曲の再生が終了し、その結果が履歴に残っている。音響設備は次の運用に使える。
