# 架空のヒアリング（固定試験入力）

これはPluginのJSON直接草案の検証用であり、実在業務への人間合意ではない。

備品の持出し受付を扱う。申請者は品名と返却予定日を申し出る。受付担当は新しい受付番号を付け、品名と返却予定日を受付台帳へ記録する。品名と返却予定日は必須だが、不足時にどうするかは未決。

確認担当は受付済みの対象内容を確認し、同じ受付を確認済みとして台帳へ記録する。対象の受付番号は変えない。代理申請の扱いもまだ決めていない。場所に条件はない。

## 固定された追加指示

台帳の表示名を「持出受付台帳」にする。確認済みを記録した後、確認担当が受付番号と確認結果を通知する仕事を追加する。通知先の媒体は未決なので、確認通知という情報のまとまりとして表す。通知でも受付番号を変えない。
