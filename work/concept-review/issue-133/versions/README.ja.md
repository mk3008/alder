## 下書き保存

下書き保存に前提条件を設けない。入力内容・品目数・現在の業務状態を問わず保存でき、品目が０件でも保存できる。提出時の必須情報・権限判定は別の条件として維持する。旧モデルの「保存時に１品目以上」は新版へ引き継がない。

提出済み・承認済み・準備済みなどの既存申請から保存した場合、保存内容と対象申請・確定版・承認の関係、および保存後の業務状態は未決。確定した提出内容を直接変更しない条件は保持する。状態遷移図には、未決の保存後状態を推定して追加していない。

## 照合の範囲

V2βの業務設計・状態遷移は Alder の候補形式 `alder-document-package/0.4` で保存する。概念モデルの正式な文書種別は未定義のため、構造草案を別ファイルで保持する。旧版の Check Item を新版へ自動追従させておらず、新版の業務意味が全体として合意されたとみなして Check Item を生成していない。

既存のベータ Viewer は旧デモデータを表示する。V2βの概念モデルを Viewer に読み込む対応は含まない。
