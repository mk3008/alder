# データ構造の保存契約案：照合記録

対象：[保存契約案](model-contract-candidate.ja.md)、[検証項目](model-contract-checks.json)、[購買V2β](versions/README.ja.md)。修正後に、同じ作業者が読み取り専用で照合した。業務意味の人間合意や独立した第三者レビューではない。

| 検証項目 | 結果と根拠 |
| --- | --- |
| MODEL-CONTRACT-001 | 業務設計を起点とし、状態・概念・Check への参照と、業務設計へのフィードバック工程を区別。購買の BD・状態・概念の ID と参照版を実データで照合した。 |
| MODEL-CONTRACT-002 | 購買草案の２サブシステム・６概念・４レビュー範囲を照合。レビュー範囲を物理構造やサブシステムそのものとしない案を記載した。 |
| MODEL-CONTRACT-003 | ビューの情報 ID・関係・条件・例と、境界を越える２つの受け渡しを区別。現行の図中の表示行には情報 ID がないため、移行時の対応付けを残課題として明記した。 |
| MODEL-CONTRACT-004 | ID と版の参照、名前・意味の変更、追従候補と人間の再レビューを区別。追加や参照漏れは指紋だけでは検出できない限界を記載した。実装と実際の変更実験は未実施。 |
| MODEL-CONTRACT-005 | BD の無条件の下書き保存、F05 の未合意、V1 の固定ハッシュを照合。概念モデルの正式契約・任意 JSON の Viewer 読込みは未実装であると明記した。 |

部分例のロール・Activity・Object・情報・例の ID は購買 V2β に存在する。部分例を現行 0.4 の有効な文書として検証したわけではない。Check Item の購買 V2β 正式文書は作っていない。契約案の型・移行方式・購買以外での適合は、今後の実装と検証が必要。
