# 購入申請の論理モデルラフ

[操作ラフ](index.html)は見積書、確定版、現在判断、準備とCSV、分割入庫、購入しない数量、申請終結を示す明示データの見本。モデル・キー・作成Activityを表示し、カードと情報項目の選択、表示場所の切替、数量6例の切替を行える。

根拠と制約は[論理モデル案](../../../business-design/purchase-request/logical-model-review.ja.md)、検証範囲は[再レビュー](../../../business-design/purchase-request/logical-model-review-results.ja.md)を参照。正式Viewer・parser・保存機能・DDLの実装ではない。人間GUI採否前。
