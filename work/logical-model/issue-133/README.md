# 購入申請Objectの論理モデル表示ラフ

index.htmlを開く。A案は要素タブ内にモデルを先に表示し、その下に全12情報項目の表を置く。エンティティまたは表の項目を押すと配置候補と関連を強調する。B案の比較切替も残す。

各エンティティの項目は省略しない。作成Activityと作業者、作成時点を表示する。購入申請・申請品目は「備品購入を申請する」、購入結果は後続の「購入結果を登録する」に配置するという2026-10-20の本人入力に基づくラフ。承認日時など、作成後に記録する項目の条件も区別する。同じ工程という業務上の説明から、同一DBトランザクションやサービス境界を自動決定しない。

多重度1：1と1：0..1は未決の候補値として明記し、複数品目なら1：1..Nという代替候補を併記する。複数品目、上限額が総額単位か、購入結果が0..1件かは未決。Object・論理エンティティ・物理テーブルの1対1対応は定義しない。分割と所属も未採用。

独立HTMLの表示ラフであり、Viewer本体・正式BD記法・パーサ・保存・モデル生成は変更しない。最小限の表示・選択確認のみ行い、正式実装と詳細回帰/E2Eは本人GUIレビュー後に判断する。
