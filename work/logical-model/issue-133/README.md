# 購入申請Objectの論理モデル表示比較

root #133のGUIラフ。index.htmlを開き、A（要素タブ内）とB（独立モデルタブ）を切り替える。情報項目またはエンティティを押すと、配置候補・任意性・未決事項を表示する。スマホ幅では右ドロワー相当を画面幅で表示する。

購入申請ObjectのInformationを複数の論理エンティティに配分する候補図であり、物理テーブルとの対応を定義しない。エンティティ分割と所属も未採用。多重度は両端とも未決として示し、複数品目・権限判定が総額単位か・購入結果が0..1件かを確定しない。提出時必須/下書き未入力可はBDの既知条件として表示し、DBのnullable宣言に変換しない。

比較だけに使う独立HTMLで、Viewer本体・BD・正式記法・パーサ・保存・モデル生成を変更しない。状態遷移/チェック項目のタブは比較対象外のためdisabled。採用後に配置・情報源・共通化・必要な検証を決める。最小の表示/切替確認のみで、詳細回帰・E2Eテストは追加しない。
