# PCを基準にしたドロワーの幅変更

2026-10-20本人の補正：PCでのレビューを優先する。階段状で疎な配置の結果としてスマートフォンでも多少読みやすくするのであり、スマートフォンを前提にPCを狭く設計しない。

PCではページ全体の700px/ドロワー480px制限を外し、画面全幅を利用する。ドロワー初期幅は60vw。左境界のドラッグで320px〜画面幅−200pxへ変更できる。図自体は自然サイズのまま、領域が広がれば見える範囲が増える。図の階層・多重度・全15Entity/17関連は変更しない。

境界はフォーカス可能なseparator。左右キーで32px、Shift付きで128px、Home/Endで最小/最大へ変更でき、ダブルクリックで初期幅へ戻す。ドラッグの取消やcapture喪失で選択抑止を解除する。ブラウザの幅変更時には上限を再確認する。

狭い画面では同じ自然サイズの図を全幅ドロワーでスクロール閲覧し、PC用の幅変更境界は隠す。端末ごとに別のグラフ配置や縮幅は作らない。

HTML module構文を確認。実際のPC表示、ドラッグ/キーによる拡縮、狭い画面への切替と自然キャンバス保持の検証はPR #254の返却記録を参照。正式Viewer本体・業務意味・BD/Check/Skill/DDLは未変更、人間採否前の独立ラフ。
