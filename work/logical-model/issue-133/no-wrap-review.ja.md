# 幅を制限しない連続した階段配置（2026-10-20）

本人の「横幅は無制限に伸ばしてよい。折り返しに見える」を反映。前版は画面幅への縮幅こそ廃止していたが、各群を親のX座標近くから始め直していたため、段が変わると左へ戻る配置が残っていた。またカード内は280px幅で自動改行していた。

- 次の段の左端は前段全体の右端より右に置く。横幅の上限や画面幅への投影・行折り返しを設けない。
- 1→0..1の同段横並び、1→Nの右下の段を維持する。共通plannerが決めた群の依存順序を利用する。
- カード幅は見出し・各フィールド・作成Activity・担当/時点の最長行を実フォントで測定して決め、項目内の自動改行を行わない。文字サイズは維持する。
- 通常の所属線は右向きへ進む経路とし、右端へ迂回して左へ戻る経路を廃止。同段で途中のカードを飛び越える参照は上側の空間を通す。主たる所属以外の参照は破線で保持する。
- PCの右ドロワー拡縮、自然サイズの縦横スクロール、15 Entity/全項目/17関連/多重度は保持。BD・モデルの意味・正式Viewerは変更しない。

検証：全段のX位置が前段右端より右へ進むこと、全フィールドが入力と同じ1行で保持されること、最長行がカード幅内に入ること、主たる12関係の多重度による配置、15 Entity/17関係を確認。保守的な文字幅による計算では4732×2022px（実寸は実ブラウザのフォント測定次第）。実画面のスクロール・選択・拡縮はPR #254の返却記録で確認する。本人の採否前。
