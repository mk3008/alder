# 市民ギャラリーの当日運営 — 現行 Business Design

この記述は合成の現行業務を表す。担当者が以下の業務意味を確認した。負荷・遅延・損失・改善要求は報告されていない。

## Activity：避難経路を点検する

- **Why:** 当日に公開する区画の避難経路が塞がれていないことを確認する。
- **When:** 開室前、施設担当が展示室の準備を終えた後。
- **Who:** 施設担当。
- **Where:** ギャラリーの避難経路。
- **How / Input:** その日の公開区画と避難経路。
- **How / Procedure:** 通行できる状態を現場で確かめ、点検結果を施設点検記録に記す。塞がれている場合は通行可能にして再確認する。
- **How / Output:** 避難経路の点検結果。
- **Result:** 施設担当が開室前の避難経路の状態を確認した。

## Activity：展示の案内表示を点検する

- **Why:** 当日の展示作品について来場者に示す説明が、展示内容と一致することを確認する。
- **When:** 開室前、展示担当が作品の配置を終えた後。
- **Who:** 展示担当。
- **Where:** ギャラリーの展示区画。
- **How / Input:** 配置された作品と作品案内表示。
- **How / Procedure:** 作品と表示の対応を現場で照合し、結果を展示点検記録に記す。表示が違う場合は展示担当が表示を修正して再確認する。
- **How / Output:** 展示案内の点検結果。
- **Result:** 展示担当が開室前の案内表示の内容を確認した。

## 対象 Object

- **施設点検記録:** 当日の避難経路の状態と再確認結果を記す。
- **展示点検記録:** 当日の作品と案内表示の対応と修正後の確認結果を記す。

この二つは確認対象・目的・担当者・記録が異なる。片方の結果は、もう片方の判断に用いられない。
