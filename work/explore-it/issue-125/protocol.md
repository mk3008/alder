# Explore It! 補助観点の比較計画

2026-10-02。Execution: https://github.com/mk3008/alder/issues/125

## 固定条件

- baseline revision: `9d3a75442fdd064750c7410e9159ddaff8ca091b`
- baseline: `docs/behavior-derivation/functional-considerations.md`
- 入力: 同revisionの `work/behavior-derivation/inputs/{facilities-maintenance,meeting-room,purchase-request}.md` 全文。既存3ケースをそのまま再利用し、Draft表記も保持。業務相関レビューは実験上完了済みと仮定する。
- A: baselineのみ。B: 同一prompt + [heuristic.md](heuristic.md)。
- 各case/armを別Fresh agentで1回ずつ、計6回。反復・平均・統計的優位の主張なし。
- 要求設定: gpt-6-sol / medium / fork_turns none。有効runtime設定の独立証明は不可。
- 原資料は発表資料の該当slideを実験担当者が読み、任意観点へ要約した。書籍全体の再現ではない。
- A/Bは先行出力を共有しない。レビュー担当者は非盲検。同一出力上で後付け採点する。
- 本番Skill、レビュー知識、Business Designは変更しない。

## 評価

結果を見る前に次の分類と判断基準を固定する。
1. 新規で有用な未決事項: 文書に答えがなく、対象内で通常発生し、既存規則を守る複数の結果差と判断可能な選択肢がある。
2. 既存記述から閉じられる: 規則・導出で答えが決まる。
3. 既決事項の再質問 / 重複: 答え済み、他候補と同一、または入力末尾で既に列挙された未決論点の言い換え。最後のものは未承認でも新規発見には数えず区別する。
4. 実装方式差: 人間から見た結果差を示せない。
5. 遠い仮説 / 適用根拠不足: 新規業務・未提示環境を要し対象との関係が弱い。

各候補は主分類1つ、補助注記可。複数論点を含む候補は分割して対応表を作る。追加発見は、同caseのAに意味上対応する候補がないBの分類1とする。B自己申告の発想元は因果証明としない。
質問を評価する要件: 発生場面、結果差、入力根拠、最小選択肢、未承認境界。件数と出力文字数を負荷代理値とし、実際の人間レビュー時間は測定しない。

「未探索領域」報告はB出力から、具体的対象が分かるか、次の判断へ使えるか、不要な棚卸しになっていないか、誤った網羅感を示す文言がないかを確認する。生成介入と報告介入を同時に加えるため各成分の因果効果は分離できない。

## 決定と停止

B固有の有用論点がなく負荷だけ増えるなら不採用／既存方式維持。有用な追加があっても単回揺らぎを除けないため、直ちに必須化せず任意の限定採用案または保留とする。正式採用の挙動変更は別変更へ切り出す。
6回と候補別評価でこのpilotを止める。評価困難は未確認として記録し、低件数を理由に入力追加・再試行しない。
