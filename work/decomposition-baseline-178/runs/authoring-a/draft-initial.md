# 不足一覧作成の業務設計書（草案・未承認）

決定された運用のうち、対象倉庫と共通の基準在庫数の登録、および毎朝の不足一覧作成を記述する。業務上の意味は確認待ちである。

未確認事項：不足一覧の保存期間は未決定。保存期間および過去の一覧の扱いは、この草案では定めない。

# Scope

対象は条件の登録と不足一覧の作成まで。在庫台帳の更新と商品の発注は対象外。在庫台帳は別業務が管理する。

# Object 一覧作成条件

## Scope

true

## Icon

sliders-horizontal

## Information

- 対象倉庫
- 共通の基準在庫数

# Object 在庫台帳

## Scope

false

## Icon

clipboard-list

## Information

- 対象倉庫の商品コード
- 商品名
- 在庫数

# Object 不足一覧

## Scope

true

## Icon

list-filter

## Information

- 商品コード
- 商品名
- 在庫数

# Activity 一覧作成条件を登録する

## Scope

true

## Why

不足一覧の対象倉庫と判定基準を定めるため。

## When

運用の導入時、または条件の見直しが決まった時。

## Who

倉庫担当者

## Where

設定画面

## How

### Input

(none)

### Procedure

倉庫担当者が設定画面で対象倉庫と共通の基準在庫数を入力し、一覧作成条件として保存する。保存直後には不足一覧を作成しない。

### Output

- 一覧作成条件 — 保存した対象倉庫と共通の基準在庫数

## Result

条件が保存され、次の毎朝7時の不足一覧作成で参照できる状態になる。

# Activity 不足一覧を作成する

## Scope

true

## Why

対象倉庫の欠品を見落とさないため。

## When

毎朝7時。

## Who

集計システム

## Where

社内の一覧保管先

## How

### Input

- 一覧作成条件 — 保存済みの対象倉庫と共通の基準在庫数
- 在庫台帳 — 対象倉庫の商品コード・商品名・在庫数

### Procedure

集計システムが保存済みの一覧作成条件と在庫台帳を読み、対象倉庫で在庫数が共通の基準在庫数を下回る商品のコード・商品名・在庫数を商品名順に並べ、不足一覧を社内の一覧保管先に保存する。

### Output

- 不足一覧 — 商品名順に並べた不足商品のコード・商品名・在庫数

## Result

その朝の不足一覧が社内の一覧保管先に保存される。
