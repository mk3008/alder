# 社内研修教材の複写・受取棚準備 業務設計書（草案・未承認）

この草案は、提示された説明だけを基に、申込票と原本が揃った後の業務を記述する。業務上の意味は未承認。

未確認事項：原本に読めないページがある場合、複写担当はどこまで作業を進め、誰へ何を伝え、受取棚への準備や作業台帳への記録をどう扱うか。これは「教材を複写して準備する」の正常な完了条件と例外時の引継ぎに関わるため、確認が必要。

# Scope

別部署で承認された申込票と社内教材の原本が揃った後、指定ページを指定部数だけ複写し、申込番号付き表紙を各部に付けて資料室の受取棚に置き、作業台帳に準備完了を記録するまでを対象とする。申込の受付・承認および完成品の引渡しは対象外。

# Activity 教材を複写して準備する

## Scope

true

## Why

社内研修に使う人数分の教材を受取棚に準備するため。

## When

別部署で承認された申込票と社内教材の原本が揃ったとき。

## Who

複写担当

## Where

資料室

## How

### Input

- 承認済み申込票 — 申込番号、指定ページ範囲、部数
- 社内教材の原本 — 指定ページの複写元

### Procedure

1. 複写担当は、承認済み申込票の指定ページ範囲と部数を確認し、社内教材の原本から指定ページを指定部数だけ複写する。
2. 複写担当は、申込票の申込番号を記した表紙を複写物の各部に付ける。
3. 複写担当は、完成した一式を資料室の受取棚に置く。
4. 複写担当は、作業台帳に申込番号、部数、準備完了を記録する。

### Output

- 資料室の受取棚 — 申込番号を記した表紙付きの複写物一式
- 作業台帳 — 申込番号、部数、準備完了の記録

## Result

指定された複写物一式が資料室の受取棚に置かれ、作業台帳に準備完了が記録されている。これにより、対象外の完成品引渡し業務が受取棚の一式を扱える。
