# Case 1

元要求：物流室では、配布担当が集荷担当の確定した到着明細を受け取ったら、本社宛て社内便の配布リストを作ります。封筒の行き先を迷わず確認できるようにするためです。到着明細には封筒番号と宛先の部署コードがあり、配布担当は総務管理の部署台帳から部署名を照合します。対象の部署コードはすべて台帳登録済みです。部署コードごとに封筒番号をまとめ、部署コード順、同じ部署内は封筒番号順に並べ、配布リストを物流室のリスト保管先に保存します。今回はこのリスト作成を扱い、社外郵便と実物の配達は含めません。リストの保存期間は未決です。

記述対象：上記の運用。未決事項：配布リストの保存期間。

# Scope

本社宛て社内便の配布リスト作成を対象とする。配布担当が確定済みの到着明細を受け取り、封筒番号と部署コードを読み、部署台帳で部署名を照合して、部署コードごとに封筒番号をまとめる。部署コード順、同じ部署内は封筒番号順に整えた配布リストを物流室のリスト保管先に保存する。社外郵便と実物の配達は対象外とする。

# Activity 到着明細受領後の配布リスト作成

## Scope

true

## Why

社内便の封筒の行き先を迷わず確認できるようにする。

## When

集荷担当が確定した到着明細を受け取ったとき。

## Who

配布担当

## Where

物流室。

## How

### Input

- 到着明細 — 確定済みの封筒番号 / 宛先の部署コード
- 部署台帳 — 部署コード / 部署名

### Procedure

1. 配布担当は到着明細から封筒番号と宛先の部署コードを読み取る。
2. 部署台帳の部署コードと照合して部署名を確認し、部署コードごとに封筒番号をまとめる。
3. 部署コード順、同じ部署内は封筒番号順に並べた配布リストを作り、物流室のリスト保管先に保存する。

### Output

- 配布リスト — 部署コード / 部署名 / 部署別の封筒番号

## Result

本社宛て社内便の行き先と封筒番号を確認できる配布リストが保管され、後続の配達で参照できる。

# Case 2

元要求：特別展では、他館から借りて会場で展示中の資料について、変化を後から追えるよう状態点検を行います。展示担当者は毎日の開館前点検の開始時刻になったら、資料管理担当が管理する借用資料台帳から資料番号、展示場所、展示開始時の状態写真を確認し、会場で各資料の現在の状態と見比べます。変化の有無にかかわらず、資料番号、点検日、観察した状態と写真との差異を点検簿に記録します。点検簿は資料管理担当が対応を判断する際に参照します。この仕事は特別展の開催期間中に展示している借用資料だけを扱い、自館の収蔵品、展示前後の検品、修復、貸借契約の変更は含めません。点検簿の保存期間はまだ決まっていません。

記述対象：上記の運用。未決事項：点検簿の保存期間。

# Scope

# Activity 展示中の借用資料を点検する

## Scope

true

## Why

展示中の借用資料の状態変化を後から追えるようにする。

## When

当日の開館前点検の開始時刻になったとき。

## Who

展示担当者

## Where

特別展の展示会場。

## How

### Input

- 借用資料台帳 — 資料番号 / 展示場所 / 展示開始時の状態写真
- 展示中の借用資料 — 現在の状態

### Procedure

1. 展示担当者は借用資料台帳から資料番号、展示場所、展示開始時の状態写真を確認する。
2. 会場で展示中の借用資料を観察し、現在の状態と展示開始時の状態写真を見比べる。
3. 変化の有無にかかわらず、資料番号、点検日、観察した状態と写真との差異を点検簿に記録する。

### Output

- 点検簿 — 資料番号 / 点検日 / 観察した状態 / 展示開始時の状態写真との差異

## Result

展示中の借用資料の当日の状態と展示開始時からの差異が点検簿で確認でき、資料管理担当が対応の判断に利用できる。
