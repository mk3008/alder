# 資料準備業務の研究用モデル

## この入力の位置づけ
行政資料の受領から画像化への受渡しという既存事例の構造を基にした仮想モデルである。以下はこの研究内で固定した条件であり、当該組織の実際の改善前の事実ではない。実運用の承認や改善の採用はない。未知を全て埋めてからでなく、与えたcontextの範囲で条件付き候補や質問を返せる。

# Scope

資料を受け付け、後続の担当が必要な資料を利用できる状態にするまで。後続の審理・裁定の内容は対象外。

# Object 資料記録

## Scope
true

## Icon
file-text

## Information
- 案件を識別する情報
- 受領した原資料と受領記録
- 原資料に対応する画像
- 処理担当と完了記録

# Activity 資料を受け付ける

## Scope
true

## Why
後続で使う資料を案件に対応づけて受け付ける。

## When
資料が届いたとき。

## Who
受付担当

## Where
資料準備窓口

## How

### Input
- 資料記録 — 案件情報 / 届いた資料

### Procedure
1. 受付担当が届いた資料を案件と対応づけ、受領記録を残す。
2. 画像化する資料と受領記録を、画像担当が参照できる状態にする。

### Output
- 資料記録 — 案件に対応づけた原資料 / 受領記録

## Result
受領が記録され、対象の原資料を画像化に使える。

# Activity 資料を画像化する

## Scope
true

## Why
後続の担当が案件に対応する資料を利用できるようにする。

## When
受領が記録され、対象の原資料が画像化に使えるようになったとき。

## Who
画像担当

## Where
資料準備窓口

## How

### Input
- 資料記録 — 案件に対応づけた原資料 / 受領記録

### Procedure
1. 画像担当が原資料を画像にし、案件との対応、判読可能性、必要な頁が揃うことを確認する。
2. 画像と処理担当・完了の記録を残す。

### Output
- 資料記録 — 案件に対応する画像 / 処理担当と完了記録

## Result
後続の担当が、案件との対応と必要な頁を保った判読可能な資料画像を利用できる。

## Problem
受領後の資料が画像担当の対応待ちとなり、利用可能になるまでの待ちが生じている。

## Pain level
Medium

## 共通の確認条件と未確認事項
以下も研究用の仮定であり、実例について確認した事実ではない。
- 受付担当と画像担当のどちらも、受領処理と画像作成の技能確認を済ませている。
- 両者は同じ資料への取扱い権限を持ち、同じ画像作成道具と記録にアクセスできる。
- 通常の対象量では、どちらにも資料準備作業に使える余力がある。繁忙時の容量と個別の時間短縮幅は未測定。
- 後続で使える資料の品質、案件との対応、必要な頁、情報の取扱い、誰が処理したかの追跡は維持する。
- 担当を分ける理由と別人実施の要否は、別途渡す条件ファイルの内容に従う。
