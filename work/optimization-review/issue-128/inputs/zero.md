# 証憑確認 — zero / no-change control

## Activity
What: 一回限りの承認済み購入の証憑を確認する。
Why: 真正な証憑であることを人間が判断する。
Who: 証憑確認責任者。
When: 証憑が届くとき。
Where: 規定なし。
Input: その購入の証憑。
How: 責任者が真正性を一回だけ確認し、結果を記録する。
Output: 判断者と確認結果が保持される。

## 制約とReview input
確認も記録も既に一回だけで、重複はない。記録支援も利用済み。人間による真正性確認を省略・委譲・機械化しないことは固定条件。
Problem: その一回の人間による真正性確認に手間がかかる。
Pain: Low
他の負担、反復需要、外部サービスや隣接業務の事実はない。固定条件を緩める権限も今回ない。
