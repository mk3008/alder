# 備品貸出の業務設計

この合成例は、以下の確定範囲を依頼者が確認済みで、業務相関レビュー済み。返却前の予約を認めるかは未決であり今回の業務範囲外。

# Object 備品
## Information
- 備品番号、貸出状態（貸出可能／貸出中）
# Object 利用者
## Information
- 利用者番号
# Object 貸出記録
## Information
- 備品番号、利用者番号、貸出日時、返却日時
# Activity 備品を貸し出す
## Why
備品を利用者へ渡す
## When
利用者が備品番号を指定して貸出を求めたとき
## Who
受付担当
## Where
受付
## How
### Input
- 備品 — 番号と現在の貸出状態
- 利用者 — 利用者番号
### Procedure
1. 貸出可能な備品なら、利用者に貸し出し、貸出記録を作成して貸出中にする。
2. 貸出中なら貸し出さず、既存の貸出記録を変えない。
### Output
- 貸出記録 — 貸出した備品、利用者と日時
## Result
貸し出した備品と借り手が記録され、返却時に貸出を特定できる。
# Activity 備品を返却する
## Why
返却を受け付ける
## When
利用者が備品を受付へ返したとき
## Who
受付担当
## Where
受付
## How
### Input
- 貸出記録 — 対象備品の現在の貸出
### Procedure
1. 対象の貸出記録に返却日時を記録し、備品を貸出可能へ戻す。
### Output
- 貸出記録 — 返却日時を記録した貸出
- 備品 — 貸出可能な状態
## Result
返却済みの備品を次の利用者へ貸し出せる。
