# 会議室予約の業務設計書（草案・確認待ち）

対象は、社員による会議室の空き確認、予約、予約のキャンセルである。以下はヒアリング時点の記述であり、未確認事項を含む。発言時刻（10:00、15:00）は業務ルールの適用時刻ではない。

## Object：社員

- Scope: false（予約やキャンセルを行う人）
- Information: 希望する部屋・利用時刻、キャンセルしたい予約

## Object：会議室

- Scope: false（この業務では部屋自体を設定・管理しない）
- Information: 部屋の識別

## Object：予約

- Scope: true
- Information: 対象の部屋、利用時刻、予約者、予約の状態。キャンセル後の空きへの反映は未確認。

## Activity：空いている会議室を探す

- Scope: true
- Why: 利用する部屋を選べるようにする。
- When: 社員が会議室を利用しようとするとき。
- Who: 社員
- Where: 規定なし
- How
  - Input: 社員からの空き部屋を探す意向、会議室の情報、予約による利用状況。
  - Procedure: 社員が空いている部屋を探す。空きの判定に用いる情報の具体的な提供方法は未確認。
  - Output: 社員が見つけた空き部屋。
- Result: 社員は予約したい部屋を選べる。

## Activity：会議室を予約する

- Scope: true
- Why: 指定した部屋と利用時刻の利用を予約する。
- When: 社員が部屋を選び、利用時刻を指定して予約するとき。
- Who: 社員
- Where: 規定なし
- How
  - Input: 社員からの部屋と利用時刻の指定、同じ部屋の既存の予約。
  - Procedure: 社員が指定した部屋・利用時刻について、同じ部屋の予約との時間重複がない場合に予約する。予約には予約者を結び付ける。
  - Exception: 同じ部屋の予約と時間が重複する予約は受け付けない。その後の選び直しや通知方法は未確認。
  - Output: 成立した予約。
- Result: 指定した部屋と利用時刻の予約が成立する。

## Activity：当日の予約をキャンセルする

- Scope: true
- Why: 当日の予約について、適用されるルールに従いキャンセルする。
- When: 予約について当日のキャンセルが求められたとき。
- Who: 社員
- Where: 規定なし
- How
  - Input: 社員からのキャンセル対象の予約、予約者、予約に適用される業務ルール。
  - Procedure: 10:00の説明では当日の予約をキャンセルできない。15:00の説明では、10月1日からルールを変更し、予約者本人に限り当日の予約をキャンセルできる。それ以前の予約には従来のルールを適用する。対象予約にどちらのルールが適用されるか確認し、新ルールの対象で予約者本人からの依頼ならキャンセルする。
  - Exception: 従来ルールが適用される当日の予約、および新ルールが適用されても予約者本人以外からの当日のキャンセルは受け付けない。
  - Output: 受け付けた予約のキャンセル。
- Result: 条件を満たした予約のキャンセルが成立する。キャンセル後の空き状況への反映は未確認。

## 未確認事項（人による判断が必要）

1. **キャンセル／予約**：「10月1日」は何年か。「それ以前の予約」は、予約を成立させた日が10月1日より前という意味か、利用日がそれより前という意味か。たとえば9月に成立し10月に利用する予約へどちらのルールを適用するかを確認したい。
2. **キャンセル後の空き確認・予約**：キャンセルが成立した予約の部屋と時間帯は、再び空きとして探せて予約できるか。できる場合、どの時点からか。

根拠：ヒアリング記録の担当者Aによる10:00と15:00の発言、および社員による空き部屋の探索・利用時刻を指定した予約・同一部屋で時間重複する予約の拒否。15:00の発言は10:00の説明を過去にさかのぼって訂正したものではなく、適用時点と従来の予約の扱いを伴うルール変更として扱う。
