# 会議室予約の業務設計（草案・確認待ち）

対象は、社員による空き会議室の探索、利用時刻を指定した予約、予約者本人による当日のキャンセルである。ヒアリングで確認できない運用は末尾に未確認事項として残す。

## Object：会議室の空き状況

- 内容：社員が探す会議室の空き状況。情報の作成・更新方法は未確認。

## Object：予約

- 内容：予約者、会議室、利用時刻を含む予約。時刻の指定方法や予約の記録媒体は未確認。

## Activity：会議室を探して予約する

- **Why**：社員が利用する会議室と時刻を確保する。
- **When**：社員が会議室の利用を希望したとき。
- **Who**：社員。
- **Where**：規定なし。
- **How / Input**：会議室の空き状況、社員が指定する利用時刻、同じ部屋の既存予約との重複を判断するための予約情報。
- **How / Procedure**：社員は空いている部屋を探し、利用時刻を指定して予約する。同じ部屋に利用時刻が重複する予約がない場合、その予約を受け付ける。
- **How / Exception**：同じ部屋で時間が重複する予約は受け付けない。重複時の通知方法や再選択の手順は未確認。
- **How / Output**：受け付けた予約。
- **Result**：指定した部屋・利用時刻の予約が受け付けられている。

## Activity：予約をキャンセルする

- **Why**：予約者本人が予約を取り消す。
- **When**：予約者本人が自分の予約のキャンセルを希望したとき。当日も含む。
- **Who**：予約者本人。
- **Where**：規定なし。
- **How / Input**：本人がキャンセルを希望する予約。
- **How / Procedure**：予約者本人は自分の予約をキャンセルする。当日の予約もキャンセルできる。
- **How / Output**：キャンセルされた予約。
- **Result**：対象の予約がキャンセルされている。その利用時刻を再予約できるかは未確認。

## 根拠の扱い

- 担当者Aは10:00に「予約者本人でも当日の予約をキャンセルできません」と説明したが、15:00に「先ほどの説明は誤りでした。予約者本人なら当日でもキャンセルできます」と明示的に訂正した。当日の本人キャンセルについては訂正後の説明を草案に反映した。10:00と15:00は発言時刻であり、業務ルールの適用開始時刻ではない。

## 未確認事項（人による確認が必要）

1. キャンセルされた予約の利用時刻は、再び空きとして扱い、新しい予約を受け付けるか。これは空き状況と重複判定の意味を変える。
2. 当日以外のキャンセルを含め、予約者本人以外がキャンセルできる場合やキャンセル期限などの条件はあるか。現在の記録だけでは本人による当日キャンセル以外の権限・条件を確定できない。

この草案の業務上の意味と未確認事項は、担当者による確認を経て確定する。
