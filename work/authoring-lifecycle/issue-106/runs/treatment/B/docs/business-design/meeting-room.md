# 会議室予約の業務設計（草案・人間による確認待ち）

## 対象

社員による空き会議室の探索、利用時刻を指定した予約、予約のキャンセルを扱う。ヒアリングの発言時刻は発言の記録であり、業務ルールの適用開始時刻ではない。

## Object：会議室の予約

会議室、利用時刻、予約した本人、予約の状態に関わる情報。予約した本人の判定方法、キャンセル後の状態と空き枠への反映は未確認。

## Activity：空き会議室を探す

- **Why:** 利用できる会議室を見つける。
- **When:** 社員が会議室を利用しようとするとき。
- **Who:** 社員。
- **Where:** 規定なし。
- **How / Input:** 会議室の空き状況。
- **How / Procedure:** 社員は空いている部屋を探す。
- **How / Output:** 社員が見つけた空き会議室。
- **Result:** 社員は予約する部屋を選べる。

## Activity：会議室を予約する

- **Why:** 会議室の利用を確保する。
- **When:** 社員が部屋を探し、利用時刻を指定するとき。
- **Who:** 社員。
- **Where:** 規定なし。
- **How / Input:** 空き会議室、社員が指定する利用時刻、同じ部屋の既存予約。
- **How / Procedure:** 社員は部屋と利用時刻を指定して予約する。同じ部屋で利用時刻が重複する予約は受け付けない。
- **How / Exception:** 同じ部屋の既存予約と時間が重複するとき、その予約を受け付けない。社員が別の部屋や時刻を探すかは未確認。
- **How / Output:** 受け付けた予約の内容。
- **Result:** 重複しない予約が成立する。

## Activity：予約をキャンセルする

- **Why:** 予約の取り消しを扱う。
- **When:** 予約のキャンセルが求められたとき。
- **Who:** キャンセルを求める人（役割の範囲は未確認）。
- **Where:** 規定なし。
- **How / Input:** 対象の予約、キャンセルを求める人、予約の利用日。
- **How / Procedure:** 当日については、予約した本人によるキャンセルを受け付ける。
- **How / Exception:** 当日、予約した本人以外によるキャンセルは受け付けない。当日以外の条件は未確認。
- **How / Output:** 受け付けたキャンセルの結果。取り消された時間帯が予約可能になるかは未確認。
- **Result:** 本人による当日キャンセルは受け付けられる。予約枠への反映は未確認。

## 発言の整理と未確認事項

同じ担当者Aの10:00「当日の予約はキャンセルできません」に対し、15:00には「本人によるキャンセルだけは、当日でもできます。それ以外は当日キャンセル不可です」と条件が示された。後者を前者の**条件付きの具体化（refinement）**として草案に反映した。当日は本人なら可能、本人以外なら不可という説明は両立する。発言時刻だけを根拠にルールの適用時点や改定日を定めない。

- **キャンセル／予約の状態（未確認）:** キャンセルが受け付けられた予約の時間帯は再び予約可能になるか。なる場合、いつ空き状況と重複判定へ反映するか。
- **キャンセル／対象日（未確認）:** 「当日」は利用日当日を指すか。また当日以外のキャンセルは誰が、どの条件で行えるか。
- **予約／時間の重複（未確認）:** 利用時刻の端点が接する予約は重複に含むか。

この草案の業務上の意味と未確認事項は、担当者による確認を要する。
