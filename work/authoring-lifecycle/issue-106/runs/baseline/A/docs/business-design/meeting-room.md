# 会議室予約の業務設計書（確認待ちの草案）

対象は、社員による空き会議室の探索、利用時刻を指定した予約、予約者本人による当日のキャンセルです。ヒアリングの15:00の発言は、10:00の発言を明示的に訂正しています。発言時刻は業務ルールの適用開始時刻として扱いません。

未確認事項：キャンセルされた予約の時間帯が再び予約可能になるか、なる場合はいつからか。これによって空き状況の判断と重複予約の判定が変わります。予約・キャンセルの記録や空き状況の提供方法は、ヒアリングからは特定できません。

# Scope

社員の会議室予約と本人によるキャンセルを対象とします。

# Object 社員

## Scope

false

## Icon

user

## Information

- 予約を希望する部屋と利用時刻
- 本人によるキャンセルの意思

# Object 会議室の予約

## Scope

true

## Icon

calendar

## Information

- 予約した社員
- 会議室
- 利用時刻
- キャンセルの有無

# Activity 会議室を予約する

## Scope

true

## Why

社員が空いている会議室を利用するため。

## When

社員が会議室の予約を希望したとき。

## Who

社員

## Where

規定なし

## How

### Input

- 社員 — 予約の希望と利用時刻
- 会議室の予約 — 同じ部屋の既存予約とその利用時刻

### Procedure

1. 社員は空いている会議室を探し、利用時刻を指定して予約する。
2. 同じ部屋で利用時刻が重複する予約は受け付けない。

### Exception

- 同じ部屋の利用時刻が既存予約と重複するとき、その予約は受け付けない。次に社員がどうするかは未確認。

### Output

- 会議室の予約 — 受け付けた予約の社員・部屋・利用時刻
- 社員 — 予約を受け付けた結果

## Result

時間が重複しない予約が受け付けられ、予約者本人は当日でもその予約をキャンセルできる。

# Activity 本人が予約をキャンセルする

## Scope

true

## Why

予約者本人が予約を取り消すため。

## When

予約者本人がキャンセルするとき。当日も含む。

## Who

予約者本人

## Where

規定なし

## How

### Input

- 社員 — 本人によるキャンセルの意思
- 会議室の予約 — 本人が予約した部屋と利用時刻

### Procedure

1. 予約者本人によるキャンセルを受け付ける。当日であることを理由に拒まない。

### Output

- 会議室の予約 — 本人がキャンセルした予約
- 社員 — キャンセルを受け付けた結果

## Result

予約者本人によるキャンセルが受け付けられる。キャンセル後の空き状況への反映は未確認。
