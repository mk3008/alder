# 会議室予約の業務設計書（確認待ちの草案）

対象は、社員による会議室の探索・予約と、ヒアリングで示された当日キャンセルの取扱いである。15:00の発言は10:00の発言を「本人によるキャンセル」に関して具体化しているものとして記載する。発言時刻をルールの適用開始時刻とは扱わない。本書は担当者による確認前の草案である。

## 対象情報と関係者

- **社員**（対象外の関係者）：空いている部屋を探し、利用時刻を指定して予約する。予約本人となる場合がある。
- **会議室と空き状況**（管理範囲・参照元は未確認）：社員が探す対象。空きの判断に何を用いるかは未確認。
- **予約情報**（対象内の業務情報）：予約する会議室と利用時刻、予約本人に関する情報を扱う。記録方法や管理者は未確認。重複の判定と本人によるキャンセルの取扱いに必要な情報である。

## Activity：会議室の予約

- **Scope**：対象内。
- **Why**：社員が利用する会議室と時刻を予約するため。
- **When**：社員が会議室を予約しようとするとき。
- **Who**：社員（探索・時刻指定）。予約の受付を判断する担当・仕組みは未確認。
- **Where**：規定なし。
- **How / Input**：会議室の空き状況、社員が指定する会議室と利用時刻、同じ部屋の予約済み時間帯。空き状況と予約済み時間帯の参照元・受渡し方は未確認。
- **How / Procedure**：社員は空いている会議室を探し、利用時刻を指定して予約する。同じ会議室で時間が重複する予約は受け付けない。
- **How / Exception**：同じ会議室の予約済み時間と重複する申込みは受け付けない。社員への伝達と再選択の流れは未確認。
- **How / Output**：受け付けた予約の会議室・利用時刻と予約本人。重複した申込みの扱い・伝達内容は未確認。
- **Result**：時間が重複しない予約が受け付けられ、予約本人によるキャンセルの対象となり得る。

## Activity：予約の当日キャンセル

- **Scope**：対象内。
- **Why**：当日の予約について、本人に認められたキャンセルを扱うため。
- **When**：予約当日に、予約本人がキャンセルを希望するとき。
- **Who**：予約本人。キャンセル処理の担当・仕組みは未確認。
- **Where**：規定なし。
- **How / Input**：キャンセル対象の予約と、申出者が予約本人かどうかを判断するための情報。確認方法は未確認。
- **How / Procedure**：予約本人による当日のキャンセルを扱う。
- **How / Exception**：本人以外による当日のキャンセルは受け付けない。申出者への伝達方法は未確認。
- **How / Output**：本人によるキャンセルの結果。予約枠の空きへの反映や通知先は未確認。
- **Result**：予約本人は当日の予約をキャンセルできる。キャンセル後の会議室の空き状況は未確認。

## 未確認の業務判断

1. **当日キャンセルの範囲**：本人以外の当日キャンセルは不可という理解でよいか。また、前日までのキャンセルは誰に認め、どの条件で扱うか。これによりキャンセルの受付条件が変わる。
2. **キャンセル後の空き状況**：本人が当日キャンセルした予約の時間帯は再予約可能になるか。なる場合、いつ空き状況に反映されるか。これにより次の予約の受付結果が変わる。
3. **予約とキャンセルの連絡・責任**：重複予約を受け付けない判断、本人確認、受付・不受付の申出者への伝達を誰がどのように行うか。これにより担当と情報の受渡しが定まる。
