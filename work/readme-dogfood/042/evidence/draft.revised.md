# 工具の返却受付の業務設計（改訂草案）

業務設計レビューと試験用の模擬入力を反映した草案です。以下の確定条件は模擬入力で指定された条件であり、実際のユーザーによる業務承認を表しません。人による確認・合意はまだ済んでいません。

**模擬入力で確定した業務条件**

- 今回の対象は、登録済みの地域住民による工具の返却受付だけ。
- 照合元は貸出記録にある貸出中の工具番号と、その貸出で渡した付属品一覧。
- 番号と付属品が一致した場合だけ返却受領を確定し、返却日時を貸出・返却記録に記録する。
- 受領済みの組は点検待ちとし、まだ貸出可能にはしない。
- 番号不一致または付属品不足の場合は受領を確定せず、返却日時と点検待ちへの変更も行わない。窓口へ要確認として返す。
- 受領済みの同じ貸出を再処理しても、最初の返却日時を上書きしない。

**草案上の構造的な整理**

- 返却受付を「返却受領」の1つの Activity として記述する。貸出の受渡し確認は今回の対象から外す。
- 「返却受領担当」は作業主体を表す仮称であり、実際の責任主体は未確認。
- 照合に使う貸出情報と返却日時を、指定された記録先の呼称に合わせて「貸出・返却記録」にまとめる。帳票やシステムの構成を決めるものではない。この Object の Scope は、本業務が返却日時を記録する範囲について true とする。貸出情報の作成は対象外。
- 「返却される組」の Scope は、本業務が返却受領後の点検待ち・貸出不可という業務状態を確定する範囲について true とする。物理的な保管・管理責任や整備担当への引渡し責任が決まったことは意味しない。
- 「窓口」は要確認の返却先となる相手方として記述する。返却受領担当との具体的な役割分担は未確認。
- 入出力の参照表記を整理したが、Business Graph の出力は今回の対象に含めない。不一致時の要確認の返却は、通常の Output と分けて Exception に記述する。

**未決事項：明示的に保留するもの**

- 整備担当への物理的な引渡し方法は未決であり、今回の実装範囲には含めない。点検待ちという業務状態から、引渡し済みであることは導かない。

**未確認事項：追加の業務判断をしていないもの**

- 返却受領を確定する実際の責任主体と、要確認を受け取る窓口との役割分担。
- 整備担当への通知方法と、物理的な引渡しまでの保管・管理責任。「点検待ち」は、整備担当への通知済みを保証する記述ではない。
- 窓口で要確認となった後の調査・判断の担当と、再受付に至る手順。今回の草案では、要確認として返すところまでを記述する。

これらは確定済みの照合・受領条件と分けて残す。貸出処理、点検作業、修理、課金の内部手順は今回の対象外であり、今回の改訂のための追加質問にはしない。

# Scope

登録済みの地域住民による工具の返却受付を対象とする。窓口で番号と付属品を照合し、一致する場合の返却受領の確定、返却日時の記録、点検待ち・貸出不可の状態までを記述する。不一致または付属品不足の場合は、受領を確定せず、返却日時と点検待ちへの変更も行わず、窓口へ要確認として返す。同じ貸出の再処理でも最初の返却日時を保つ。

貸出処理、点検作業、修理、課金は今回実装しない。整備担当への物理的な引渡し方法は未決として今回の実装範囲から外す。登録業務もこの文書の対象外とする。

# Activity 返却受領

## Scope

true

## Why

工具の返却受領を確認する。

## When

工具の返却受付時。

## Who

返却受領担当（仮称）

## Where

窓口。

## How

### Input

- 返却される組 — 工具番号と付属品
- 貸出・返却記録 — 貸出中の工具番号、その貸出で渡した付属品一覧

### Procedure

1. 返却受領担当は、窓口で返却される組の工具番号と付属品を、貸出・返却記録にある貸出中の工具番号と、その貸出で渡した付属品一覧に照合する。
2. 返却受領担当は、番号と付属品の一致を確認し、返却受領を確定する。
3. 返却受領担当は、返却日時を貸出・返却記録に記録する。同じ貸出の再処理でも、最初に記録した返却日時を上書きせず保つ。
4. 返却受領担当は、受領済みの組を点検待ちとし、まだ貸出可能にはしない。

### Exception

- 番号不一致または付属品不足の場合は、返却受領を確定せず、返却日時を記録せず、点検待ちへの変更も行わない。窓口へ要確認として返す。
- 要確認を受け取った後の窓口での調査・判断と再受付の手順は未確認であり、再開条件や別 Activity への遷移はこの草案で定めない。

### Output

- 貸出・返却記録 — 返却日時
- 返却される組 — 点検待ち・貸出不可の状態

## Result

番号と付属品が一致した組の返却受領が確定し、貸出・返却記録に最初の返却日時が保持されている。受領済みの組は整備担当の点検待ちであり、まだ貸出可能ではない。物理的な引渡しや整備担当への通知が完了したことは、この状態の確定に含めない。
