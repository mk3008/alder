# 給与振込の業務設計書（確認待ちの草案）

## 対象と業務上の条件

対象は、従業員の給与額・振込先の確認から、承認、銀行への振込依頼、銀行の処理結果の照合、完了記録までの給与支払業務と、振込先の変更である。銀行の処理自体は銀行の業務である。

- 指定した給与日の17時までに、対象者全員の振込が完了していることが必要である。
- 同じ従業員の同じ月の給与を、依頼の再送や一部失敗後のやり直しによって二重に支払ってはならない。
- 振込先の変更は経理責任者の承認後に反映する。変更した人・時刻・変更前後の情報を、翌年度末まで後から確認できる必要がある。

銀行への具体的な送信方式、ストレージ、冗長構成は未選定であり、この草案では定めない。

## 業務

### 振込先の変更

- **Scope:** true
- **Why:** 承認された振込先変更を反映し、変更の経緯を確認できるようにする。
- **When:** 振込先の変更が必要になったとき。変更の申出元と受付方法は未確認。
- **Who:** 経理担当、経理責任者（承認）。
- **Where:** 規定なし。
- **How — Input:** 振込先の変更内容（申出元は未確認）、現在の振込先情報。
- **How — Procedure:** 経理責任者が変更を承認する。承認後に振込先を反映する。変更した人・時刻・変更前後の情報を、翌年度末まで後から確認できるようにする。
- **How — Output:** 承認後に反映された振込先と、確認可能な変更履歴。
- **Result:** 承認された変更が振込先に反映され、後から変更の経緯を確認できる状態になる。

### 給与額・振込先の確認と振込依頼の承認

- **Scope:** true
- **Why:** 対象者への給与振込の依頼内容を確認し、承認を得る。
- **When:** 毎月の給与振込を準備するとき。具体的な開始日・締切は未確認。
- **Who:** 経理担当、経理責任者（承認）。
- **Where:** 規定なし。
- **How — Input:** 従業員ごとの給与額と振込先。情報の確定元は未確認。
- **How — Procedure:** 経理担当が毎月、従業員ごとの給与額と振込先を確認し、経理責任者の承認を受ける。
- **How — Output:** 承認された振込依頼の対象者、給与額、振込先。
- **Result:** 銀行への振込依頼に進むための承認が得られる。

### 銀行への振込依頼

- **Scope:** true
- **Why:** 承認された内容で給与振込を銀行に依頼する。
- **When:** 経理責任者の承認を受けたとき。
- **Who:** 経理担当。
- **Where:** 銀行への依頼。具体的な送信方式は規定なし。
- **How — Input:** 承認された振込依頼の対象者、給与額、振込先。
- **How — Procedure:** 経理担当が銀行へ振込を依頼する。同じ従業員の同じ月の給与が、依頼の再送や一部失敗後のやり直しによって二重に支払われないようにする。
- **How — Output:** 銀行への振込依頼内容。
- **Result:** 銀行に振込が依頼され、処理結果の受領を待つ状態になる。依頼だけでは振込完了とはしない。
- **How — Exception:** 銀行が一部失敗を返した場合の再依頼または別の処理は未決定。未完了分の扱いと完了分の確認方法を決める必要がある。

### 処理結果の照合と完了記録

- **Scope:** true
- **Why:** 銀行の処理結果から対象者と金額を確かめ、給与振込の完了を記録する。
- **When:** 銀行の処理結果を受け取ったとき。
- **Who:** 経理担当。
- **Where:** 銀行からの結果受領。具体的な受領方式は規定なし。
- **How — Input:** 銀行の処理結果、依頼した対象者と金額。
- **How — Procedure:** 経理担当が銀行の処理結果を受け取り、対象者と金額を照合して完了を記録する。
- **How — Output:** 照合した結果と完了記録。
- **Result:** 照合した振込の完了が記録される。給与支払業務としては指定した給与日の17時までに対象者全員の振込完了が必要である。
- **How — Exception:** 一部失敗の結果を受けた場合、完了した分と未完了分をどう確定し、未完了分をどう扱うかは未決定。依頼の再送・やり直しでも同じ従業員の同じ月の給与の二重払いは禁止する。

## 関係する情報と相手

| 対象 | Scope | 業務に必要な情報・授受 |
| --- | --- | --- |
| 従業員ごとの給与額・振込先 | true | 経理担当が確認する給与額と振込先。確定元と変更の受付元は未確認。 |
| 振込先の変更履歴 | true | 変更した人、時刻、変更前後の情報。翌年度末まで後から確認できる必要がある。 |
| 承認された振込依頼内容 | true | 対象者、給与額、振込先、および経理責任者の承認。 |
| 銀行 | false | 振込依頼を受け、処理結果を返す相手。銀行内部の処理は対象外。 |
| 銀行の処理結果 | false | 経理担当が対象者と金額を照合するために受け取る結果。一部失敗が返る場合もある。 |
| 完了記録 | true | 銀行の結果と対象者・金額を照合して記録する振込の完了。 |

## 現在の困りごと

- **Problem:** 先月、一人の振込が指定日の翌朝となり、経理担当が原因の確認と本人への連絡に約2時間を要した。事業責任者はこれを現在の困りごとと認めている。
- **Pain level:** Medium。

この事例から、遅れが毎月発生するとまではいえない。

## 未確認・未決定の業務判断

1. **一部失敗時の結果照合と再処理（処理結果の照合と完了記録／銀行への振込依頼）:** 完了した分と未完了分をどう確定するか。未完了分だけ再依頼するのか、別の処理にするのか。その際、誰が判断・実行し、銀行の結果と既存の依頼・完了記録をどう確認して二重払いを防ぐか。期限と二重払い禁止自体は確定した条件である。
2. **期限までの完了判定と遅れへの対応（処理結果の照合と完了記録）:** 銀行のどの処理結果をもって各人の「振込完了」と判断し、指定給与日の17時までの全員分の完了を誰がどう確認するか。完了が間に合わない見込みまたは遅れを認識した際の連絡・対応は誰が担うか。
3. **振込先変更の受付と記録（振込先の変更）:** 変更を誰から、どの情報を受けて扱うか。承認と反映を誰が行い、「変更した人」をどう特定するか。変更が月次確認・承認・依頼の途中で生じた場合、どの振込先を使用し、関係者にどう伝えるか。
4. **月次依頼の根拠（給与額・振込先の確認と振込依頼の承認）:** 対象者・給与額・振込先の確定した情報はどこから受け取り、承認後の変更が必要な場合には誰が再確認・再承認するか。

事業責任者または該当業務の責任者による確認を経て、この草案の業務上の意味と未決事項を確定する。
