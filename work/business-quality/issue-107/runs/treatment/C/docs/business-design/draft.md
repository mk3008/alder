# 窓口受付と月末集計の業務設計書（草案・未確認）

ヒアリングに記載された窓口受付から月次報告までを対象とする。以下は依頼者による確認前の草案であり、未決事項を確定した業務規則として扱わない。

## Object：市民の申請

**Scope:** false（市民から受け取るもの）

申請の内容。申請内容の項目や受付可否の判断基準はヒアリングにない。

## Object：受付記録

**Scope:** true

受け付けた申請と受付時刻を残す記録。月次の受付件数の集計元となる。紙で受け付けた分は復旧後に転記するが、転記や確認の運用は未決。

## Object：受付結果

**Scope:** true

窓口担当が市民に渡す受付結果。内容や形式は未確認。

## Object：月次受付件数報告

**Scope:** true

受付記録から集計した月次の受付件数を窓口責任者に伝えるもの。形式は未確認。

## Activity：申請の受付

**Scope:** true

### Why

市民の申請を受け付け、受付の結果を伝える。

### When

平日の9時から17時までに市民の申請を受けるとき。

### Who

窓口担当

### Where

窓口。情報システム停止時には、必要に応じて紙による受付を行う。

### How

#### Input

- 市民の申請 — 市民が提出する申請

#### Procedure

1. 窓口担当が市民の申請を受け付ける。
2. 受け付けた申請と受付時刻を受付記録に残す。
3. 窓口担当が市民に受付結果を渡す。

#### Exception

- 利用している情報システムが止まっても受付業務を続ける。必要なら紙で受け付け、復旧後に受付記録へ転記する。紙での運用詳細と転記確認の担当者は未決。

#### Output

- 受付記録 — 受け付けた申請と受付時刻
- 受付結果 — 市民に渡す受付結果

### Result

市民の申請が受け付けられ、受付結果が渡される。受け付けた申請と受付時刻は受付記録に残り、月次集計の対象となる。紙で受け付けた分の転記までの扱いは未確認。

### Quality（業務品質要求・暫定）

窓口責任者の「この時間帯には申請を受け付けられる状態が必要」「利用している情報システムが止まっても、受付業務自体は止めず、必要なら紙で受け付けて復旧後に受付記録へ転記する」という発言に基づく。対象は申請の受付であり、平日の9時から17時まで申請を受け付けられること、情報システム停止時も受付を継続し、紙で受け付けた分を復旧後に受付記録へ反映することが成立条件である。停止時の具体的な紙の手順や転記確認の責任は未決。

## Activity：月次受付件数の集計・報告

**Scope:** true

### Why

月次の受付件数を窓口責任者へ伝える。

### When

月末に受付記録から月次の受付件数を集計するとき。

### Who

集計担当

### Where

規定なし。

### How

#### Input

- 受付記録 — 月次の受付件数の集計元となる受付情報

#### Procedure

1. 集計担当が受付記録から月次の受付件数を集計する。
2. 集計担当が窓口責任者へ月次の受付件数を報告する。

#### Output

- 月次受付件数報告 — 窓口責任者への月次の受付件数

### Result

窓口責任者に月次の受付件数が報告される。

### Quality（業務品質要求・暫定）

集計担当の「翌営業日の終了までに窓口責任者へ報告する」および窓口責任者の「集計は月末当日に即時でなくてよい」という確認に基づく。対象は月次受付件数の集計・報告であり、月末当日の即時集計は要せず、翌営業日の終了までに報告が窓口責任者へ届くことが成立条件である。

## 未確認の業務判断

1. **申請の受付：紙運用と転記の確認。** システム停止時に紙へ何を記録し、受付結果をどう渡すか。復旧後、誰がいつ受付記録へ転記し、誰が申請・受付時刻と転記内容の一致や転記漏れを確認するか。これにより、停止時の結果と月次集計につながる記録の責任が定まる。
2. **月次受付件数の集計・報告：集計範囲。** 月次件数はどの受付時刻・期間を基準とし、月末に紙で受け付けて転記が翌営業日以降になる申請を、その月の件数にどう含めるか。これにより、報告する数値の意味と紙受付からの引き継ぎが定まる。

受付の遅延や損失、報告期限超過の実績は聞いていないため、Problem や Pain level は設定していない。情報システムの可用性構成と同期方式は決まっておらず、この業務設計では選定しない。
