# 宣言から生成した状態遷移

部分定義。未記載の操作は未決。終端は未決。条件の真偽・業務整合性は判定しない。

```mermaid
flowchart TD
  S0["下書き"]
  S1["差戻し"]
  S2["submitted"]
  S3["approved"]
  S4["purchased"]
  START["開始候補：記録作成前（非保存状態）"]
  NONE["申請不成立（記録を作成しない）"]
  START -->|"T01 備品購入を申請する"| S2
  START -->|"T02 備品購入を申請する"| S0
  START -->|"T03 備品購入を申請する"| NONE
  S2 -->|"T04 購入申請を承認する"| S3
  S2 -->|"T05 購入申請を承認する"| S1
  S0 -->|"T06 購入申請を再申請・破棄する"| S2
  U07["T07：遷移先未決（保存状態ではない）"]
  S0 -.->|"T07 購入申請を再申請・破棄する"| U07
  U08["T08：遷移先未決（保存状態ではない）"]
  S0 -.->|"T08 購入申請を再申請・破棄する"| U08
```
