# 生成構造の観測メモ

C1/C2文脈評価確定後のoperatorによる資料読解。採点者へ渡さず、固定scoreの変更に用いない。構造が存在することと、実利用で有効であることを分ける。

- C2 RDRA Stage2 r1のP002は、会議室利用状態・予約状態、BUC、活動、UC、情報、条件、From/To状態を同じ行へ関係付けている。停止時の検索、新規予約、変更先、既存予約維持はcanonical F16–F19に保持され、取消後の検索/予約の即時復帰はF13/F14に分けられた。具体的な変更影響を追う入口になる構造を生成した。ただし、実際の横断影響分析作業・変更後追従・利用者の時間節約は試していない。同時要求保証の未決がこのrepでは直接評価canonicalにない点と両立する。
- C2 Alder Stage2 r1のP058は、未確認事項を先に置き、会議室/予約Objectと空室検索・予約・変更・取消・停止のActivityをInput/Procedure/Output/Resultとして記述する。取消から検索/新規予約への復帰はF7/F9、停止の変更先・新規予約・既存予約維持はF13/F22/F23、同時要求の未決はF19で保持された。未決をconfirmedな期待結果に昇格しなかったが、非専門家の理解速度や合意の成功率は計測していない。
- C1では両手法が未決2項目を発見し、固定回答後の全4probeが必要事実11/11を伝えた。Alderの判定Resultから貸出Inputへの連続性はP019 F7/F17、P025 F11–F19に、RDRAの区分/許否構造はP005 F6–F9、P029 F3–F5に残った。共通下流coverageに差がない観測を、構造の違いだけで勝敗へ変更しない。

- 下流coverage分母は未決・scopeを除いた必要期待結果である。C1 P029のStage2欠落は「他の貸出条件は試験範囲外」、C2 P002の欠落は「同時予約保証と順序は未決」。全probeの期待結果coverageが一致しても、範囲/未決の引渡しが同じだと結論しない。これらはStage2 coverageと原文notesで別に読む。

詳細は各匿名packet、canonical、原scoreのcoverage_evidenceとnotesへ遡れる。無断決定や補完の原文曖昧性は最終集計の該当metric NAを維持し、このメモで解消しない。
