# 蔵書の貸出に関する業務設計書（草案・要確認）

対象は蔵書の貸出と、返却遅延時の貸出制限である。以下はヒアリングで確認できた意味だけを記し、許否や区分の未決定事項を合意済みの規則として扱わない。

## Activity: 蔵書の貸出

### Scope

true

### Why

蔵書を貸し出す。

### When

蔵書の貸出を行うとき。開始の具体的な契機は未確認。

### Who

貸出を行う役割（名称・責任者は未確認）。

### Where

規定なし。

### How

#### Input

- 蔵書：貸出対象の蔵書。
- 会員・返却遅延の情報：会員種別と遅延日数。

#### Procedure

1. 貸出を行う役割が、貸出対象の蔵書、会員種別、遅延日数を扱う。
2. 返却遅延時には、遅延日数と会員種別を判断材料として貸出制限を扱う。区分の解釈と区分ごとの貸出許否は未決定であり、この草案では判断結果を定めない。
3. 貸出が認められる場合の具体的な手続と記録方法は未確認。

#### Output

- 貸出結果：実際に貸し出した結果。制限による不許可の通知・記録の有無と内容は未確認。

### Result

認められた貸出について蔵書が貸し出される。返却遅延時の各条件で貸出を認めるかどうかは未決定。

## Object: 蔵書

### Scope

false

### Information

貸出対象の蔵書。貸出業務より前に蔵書を管理する仕事の範囲と担当は未確認。

## Object: 会員・返却遅延の情報

### Scope

false

### Information

会員種別（大人・子供）と遅延日数。これらを確定・維持する仕事の範囲と担当は未確認。

## Object: 貸出結果

### Scope

true

### Information

貸し出された蔵書に関する結果。結果に含む情報、制限時の結果の扱い、記録・通知の有無は未確認。

## 未確認事項（合意前の判断）

1. **貸出の判断条件：日数区分。** 「3日未満」と「7日未満」は文言上重なる。互いに排他的な区分として「3日未満」「3日以上7日未満」「7日以上」を意図するのか、別の解釈なのか。遅延日数の起点と端数の扱いも、境界日の貸出可否に影響するため確認が必要。
2. **貸出の判断条件：許否。** 大人・子供それぞれについて、確定した日数区分ごとに貸出を認めるか、制限するか。制限が貸出不可以外の意味を持つ場合は、その具体的な貸出結果も確認が必要。
3. **貸出の責任と結果の引渡し。** 誰が貸出可否を判断し、貸出または制限の結果を誰にどう伝えるか。これはActivityのWho、Output、および制限時の後続行動を変える。

この草案は業務上の合意前であり、未確認の判断を実装規則として使用しない。
