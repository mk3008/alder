# 蔵書貸出の業務設計（草案・確認待ち）

対象は、会員種別と返却遅延日数による貸出許否の判断と蔵書の貸出である。これ以外の貸出条件は本設計の対象外とする。日数区分と許否はヒアリング結果に付された固定Human answerを反映した。担当者は未確認である。

## Activity: 蔵書を貸し出す

### Scope

true

### Why

会員種別と返却遅延日数に応じて貸出制限を適用し、貸出可能な場合に蔵書を貸し出す。

### When

蔵書の貸出を行うとき。

### Who

貸出担当者（仮称・未確認）。

### Where

規定なし。

### How

#### Input

- 貸出判断に用いる情報：会員種別（大人／子供）と返却遅延日数。
- 貸出対象の蔵書。

#### Procedure

1. 貸出担当者は、貸出判断に用いる情報から会員種別と返却遅延日数を確認する。
2. 遅延日数を、0日以上3日未満、3日以上7日未満、7日以上のいずれか一つに区分する。
3. 会員種別と日数区分により、次のとおり貸出許否を判断する。

   | 会員種別 | 0日以上3日未満 | 3日以上7日未満 | 7日以上 |
   | --- | --- | --- | --- |
   | 大人 | 貸出可 | 貸出不可 | 貸出不可 |
   | 子供 | 貸出可 | 貸出可 | 貸出不可 |

4. 貸出可の場合は蔵書を貸し出す。貸出不可の場合は貸し出さない。

#### Output

- 貸出結果：貸出した、または貸出しなかったという結果。

### Result

会員種別と返却遅延日数による制限に従って、貸出可の場合は蔵書が貸し出され、貸出不可の場合は貸し出されていない。

## Object: 貸出判断に用いる情報

### Scope

false

### Information

- 会員種別（大人／子供）
- 返却遅延日数

本業務が受け取る判断材料を表す。情報の作成元や遅延日数の算出方法は、このヒアリングでは示されていない。

## Object: 貸出対象の蔵書

### Scope

false

本業務が貸し出す対象。蔵書の管理方法は対象外。

## Object: 貸出結果

### Scope

true

### Information

- 貸出した／貸出しなかった

本業務によって成立する結果を表す。結果を記録・通知する手段や相手は未確認であり、この草案はそれらを規定しない。
