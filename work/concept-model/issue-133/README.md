# 購買概念モデルの操作試作

root #133 / Alder #253。公開可能な架空の購買業務を使い、見せ方・操作の採否を確認する。モデルは未採用。

## 確認する

`index.html` をHTTPで開く。初期表示は全体図。上部のActivityリンクで局所図へ切り替え、カード本体を選択すると下に情報の存在条件と未決が表示される。緑は操作対象、灰は直接隣接する参照。

- カード本体をドラッグする。キーボードではフォーカスしてAlt＋矢印で移動する。
- 灰色の名前リンクから作成Activityへ移動し、「戻る」またはブラウザーBackで戻る。選択・図のスクロール・配置を復元する。
- 版・品目は申請と再申請の両方で作るため、単一の作成Activityへリンクしない。選択詳細で両方を案内する。
- 「自動配置に戻す」はその図だけを初期化。「配置をコピー」は座標をJSONでコピーする。

全体図6概念／6関係。局所図は操作対象から直接隣接する関係だけで、灰から再帰展開しない。隠れた品目や見積の業務上の確認義務は各Activityの説明に残す。

基点はリリース後main `30b8b2a2`。Viewer本体の全体／Activity詳細と要素表示の使い方を、隔離した部品試作として検討する。既存Viewerの表示・保存・parserには組み込まない。独立したBモデルタブやObjectと概念の1対1対応を追加しない。

- UX参考：旧PR #254 `6e55d98710a1d8757937ea268176929abcf49b2e` の `work/logical-model/issue-133/`。独立配線器と選択・ドラッグ・履歴復帰を流用。自然幅・縦横スクロール・両端数値・工程別配置を維持。
- 仮fixture：PR #266 `cbb3073b42b86323e152b20ac899589f1686d61c` の model / activities。`index.html` 冒頭の `tables / edges / activityDefinitions / creatorStages` は描画専用の構造化データ。正式conceptModel契約ではない。
- 廃止した前提：旧6テーブル、独立した確定・判断・見積テーブル、PK/FK、下書き／提出を別Activityにする表示、前半3工程だけの全体図。
