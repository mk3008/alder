## 確認する

`index.html` をHTTPで開く。初期表示は全体図。上部のActivityリンクで局所図へ切り替え、カード本体を選択すると下に最初から展開した情報の存在条件と未決へ移動する。個別図は操作対象のみ。参照概念は表示しない。全体図では6概念を表示する。

- 全体図だけカード本体をドラッグできる。キーボードでは配置ロックOFFでAlt＋矢印。個別図はドラッグ不可。
- 概念カードをクリックすると最初から展開された説明へ移動する。ブラウザーBackで元の図のスクロール・倍率・選択・フォーカスへ復帰する。説明内の作成Activityリンクは移動先を明示する。
- 版・品目は申請と再申請の両方で作るため、単一の作成Activityへリンクしない。選択詳細で両方を案内する。
- 配置リセット・座標コピー・保存状態の表示は、本人の青枠指定に従って削除した。

全体図6概念／6関係。個別図は登録・更新・対象外化する概念だけを表示し、その両端が表示される関係だけを残す。参照概念は非表示。隠れた品目や見積の業務上の確認義務は各Activityの説明に残す。

## 階段配置と独立した接続口

全体図は準備→申請→版→品目→入庫回→入庫内訳の順に、カードの実高に合わせて右下へ続く階段にする。黄色注記は経路の見本であり、線の色は従来の灰色を使う。申請→入庫回は版・品目の左側を通る。旧 `example=receipt-low` 専用配置は廃止し、通常表示で階段配置を開く。

接続口・引出線・件数表示は関係ごとに独立させる。相手の位置に応じて接続口の順序を変え、長い下方向の関係は近い関係より左から出す。参照線は階段の右外側に出入りし、左側の着地線と交差しないようにする。経路探索も交差・接触を避ける経路を優先する。接続口の統合は行わない。

`node work/concept-model/issue-133/verify-routing.mjs` は通常の階段配置で交差・接触0を確認し、旧7配置の独立接続口・6線／12端数値・線分非共有・数値非重複を回帰検査する。任意配置での交差回避・接続の完全性は保証しない。原画像はpublicへ転載しない。
