# Solution-shaped request intake: bounded protocol

Status: research only; preregistered before agent output. No product Skill modification or adoption.

Control revision: `a971d60bb64fbc048a871d70dda277c93b680288` (main resolved 2026-10-04). Use the main checkout's two Skill files, their bundled authorities and provenance; the author's bundled authority may intentionally point to an older source revision. Also read the Business Design quality-check and structure pages at the Control revision. This tests explicit provision of these texts, not automatic client routing or installed-plugin behavior.

Inputs: `cases.md`, `treatments.md`, and the source manifest at this study's immutable public input commit. Confirm the commit and files are retrievable before a run. Source packet: authoring Skill, whole bundled adoption section 1 (ending at section 2), bundled Business Graph specification through the minimal example if producing its optional profile; Optimization Skill and full bundled Optimization authority; docs/business-design-quality-check.ja.md and docs/business-design-structure.ja.md. No historical study, other arm or evaluator analysis is an input.

Design: four new no-history contexts, requested `gpt-6-sol`, reasoning effort `medium`, one per Control/A/B/C, each receiving the same six independent scenarios in the same order and only its assigned additive paragraph. Thus 24 case responses, but only four independently started agent contexts. Case order and within-batch carryover are limitations; do not report 24 independent samples. No stochastic significance, universal improvement or client-routing claim. Do not use the investigator's expected answer as a responder input.

Common task prompt:

“Act as the Alder assistant for the six separate synthetic requester conversations in cases.md. Read the permitted pinned source packet and only the assigned treatment (Control adds nothing). For each case return the actual first response you would give the requester in Japanese, including a reviewable draft excerpt when you would draft, concrete questions when needed, or routing/next action when the request belongs elsewhere. Do not implement product code or perform external actions. Keep each case separate and do not import facts or decisions across them. Apply the supplied guidance rather than critique or evaluate the experiment. After the six responses, list source paths/revisions read and any access or instruction deviations. Output to the assigned raw file; do not inspect other outputs or unassigned treatment paragraphs.”

The dispatch wrapper will record exact local readable paths, the public source and input revisions, output path and agent identifier. It adds a tool/publication safety boundary, not a desired experimental outcome. Retain full sent prompts and raw final response text after checking for sensitive material. Requested model/effort are tool arguments, not independently attested runtime. Billing/token usage and effective runtime are unknown unless the tool returns them. Record elapsed wall clock, guidance bytes, response bytes and question counts as descriptive costs, not human time savings.

Evaluation (investigator after responses): for each case/arm record (1) explicit false promotion to agreed requirement, separately (2) candidate-first anchoring without background; (3) return to current work / Problem / intended condition; (4) requester candidate retained; (5) useful alternative comparison or correct deferral; (6) human decision distinct from AI proposal; (7) necessary versus redundant questions/returns; (8) additional maintained artifacts/states. A whole-document Draft label alone is not proof of effective premise checking, and a draft proposal is not by itself false approval. An unsupported broad Why remains invented even if means-independent.

S1 must allow Problem-led exploration without forced adoption; S2/S3 test solution-only intake; S4/S5/S6 are legitimate-decision controls. No case requires invented measurements, contract facts or repeated confirmation of supplied facts. Count question intents rather than question marks; give excerpts so judgment is inspectable. Cases are designed by the investigator and may favor the hypotheses. One sampled response per cell cannot establish robustness.

Stop after the four batches if they distinguish the mechanisms or establish no observed incremental gain. A combination is an analytical recommendation unless separately run at a public frozen input revision. Do not repeat favorable or unfavorable cells merely to obtain a preferred outcome. If Control does not demonstrate the issue's alleged failure, state that the failure was not reproduced under these conditions; static gaps are not observed behavioral failure.
