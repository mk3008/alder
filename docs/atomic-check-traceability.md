# Atomic Check traceability — moved

The current name is **Check Item**. See [Check Item traceability](check-item-traceability.md).

Atomic Check is the v0.3 terminology. The rename itself did not change item granularity, Check IDs or review states. Since v0.5, current Alder keeps permanent traceability through Business Design ↔ Check Item ↔ Test and does not maintain Check Item ↔ Code location mappings. Historical release notes and research evidence retain their original terminology and evaluated mappings.
