# AI作業結果を確認しやすく返す

AIは、結果と依頼目的の対応が分かる説明を添えて返す。依頼者はその説明を入口に、目的に沿っているかを確認する。

返却時には、結論と変更の意味を先に示し、必要な根拠、未完了事項、人間が判断する点を続ける。根拠は成果物や検証記録への参照で示し、詳細は参照先で確認できるようにする。固定の表や欄を毎回埋める必要はない。

改善案には「結果レビュー：目的との対応を探す負担を減らす」のように、対象の場面と改善効果が分かるタイトルを付ける。何をAIへ移し、何を人間に残すかを示し、未採用の案を実施済みの変更と混ぜない。

例えば、読みやすさの改善案を採用した段階なら、次のように返す。

> 結果レビューを確認しやすくする案を採用済みです。AIが目的との対応、根拠、未完了事項を整理して返し、依頼者の意味判断は維持します。運用手順への反映と、実際に確認が楽になるかの評価はこれからです。

要約や検証成功は、人間の業務判断や成果の原典を置き換えない。重要な確認事項を省略しない。採用、手順への反映、実際の負荷低減は別の状態として伝える。

対象と責務は[業務設計](../business-design/ai-result-review/README.md)を参照する。
