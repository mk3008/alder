# Alder 0.4.9

JSONを明示選択した業務設計とCheckを、直接草案・更新する開発候補です。公開版のインストール先は変更していません。

## 追加

### JSON正本の草案・更新・レビュー

ヒアリングから型付きJSONを直接作成し、Activity/Objectの追加・改名・内容更新でID・版・参照・未決を保持します。Checkは対象BDの人間合意を確認してから草案を作り、既存の人間レビュー状態・共有保証・根拠・Test証拠を保ちます。確認のない承認や、構造検査の成功を使った業務合意は行いません。

### MarkdownからJSONへの一方向変換

対応するBD/Check Markdownを新しいJSONへ明示変換できます。元MDとその全文をJSON内へ二重保存する運用や、JSON→MD同期は行いません。未対応欄・不明参照・原典版不一致は診断して停止します。

## 利用条件

直接JSON操作はNode 24以上、MD変換はPython 3.12以上も必要です。既存Markdown向け機能を維持します。保存契約は候補0.1で、正式JSON v1・状態遷移/概念モデル仕様・ViewerのJSON表示を確定するものではありません。
