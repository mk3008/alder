# Alder 0.4.9

業務設計書のレビュー指摘を、根拠から一意に直せる誤り、業務判断が必要な未決事項、任意の提案に分け、処理先を明確にします。

## 変更

- 草案作成・改稿では、一意に修正できる誤りを根拠付きで直して再レビューします。WhoやWhenとProcedureの矛盾、手順・入出力の飛躍など、正解が未確定の事項は推測で補わず、草案と返答で確認を求めます。
- 未採用の追加承認や新機能などの提案は実行結果に留めます。未確認事項を無条件にFindingsへ登録しません。
- 単独の業務設計レビューは引き続き読み取り専用です。人間の採否判断を文書へ反映する際は、別の明示的な改稿依頼を使います。
