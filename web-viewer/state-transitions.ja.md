# Object右ドロワーの状態遷移図ラフ

状態遷移を明示したObjectを選ぶと、既存の右ドロワーにSVGの状態遷移図を表示します。状態は箱、遷移は矢印、結果の保存状態が未決の操作は破線で示します。開始候補・作成不成立・遷移先未決は保存状態ではありません。未記載の操作は未決です。

図の状態名は日本語に揃え、矢印は既存Activity名と明示された条件を表示します。event列の別名は表示しません。操作IDは折りたたんだ「操作の詳細」で照合します。同じ元・先・Activity・効果・通常/例外区分の操作は一本の線へ条件を併記します。Activity名から業務説明へ移動でき、原文は「原文を見る」から確認できます。

これは見た目と表現の方向性を確認するための未検証ラフです。矢印・ラベルの重なり、一般的な配置、自己ループ、操作性・回帰テストはまだ完成していません。正式BD書式やPluginの採用、完成品の機能保証とは区別します。方向性の人間レビューを先に行い、その後に必要な実装・テストを整えます。

読み込む宣言はInformation後の `## State Transitions` 内に置くPoC案A相当のメタ情報と表です。[購入申請の隔離fixture](../tools/fixtures/state-transitions/purchase-request.md)を使います。自然文から遷移を補完しません。正式BD、Findings、Check、Skill、本番配信は変更していません。

配置と配線の比較ラフでは、既存の `matrixPlan` と `routeEdge` を直接使います。状態を配置用の順序付き箱、明示された遷移を依存線として渡す表示専用アダプターです。BDのActivity/Object区分や保存データは変更しません。状態一覧の順序は表示ヒントだけに使います。戻り線・到着直線も既存ルーターに従います。図の幅は維持し、右ドロワー内で横スクロールできます。

最新比較ラフは矢印を既存Activity名と明示条件に揃え、event別名を表示に使いません。実線は通常・破線は例外（path宣言）です。短い状態名に合わせて箱を縮め、matrixPlanの階段セルを表示サイズと複数行条件の余白へ投影し、routeEdgeで配線します。保存不可は確定した非保存結果、未決は各経路の設計課題の集約注記で、どちらも保存ステータスではありません。通常のCSV出力先も現宣言では未決であり、不変を推定しません。色の強調は保留です。
