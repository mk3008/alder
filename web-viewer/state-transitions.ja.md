# Objectの状態遷移を右ドロワーで確認する

状態遷移を明示したObjectを選ぶと、既存の右ドロワーに状態一覧と遷移元・遷移先・条件・結果・根拠Activityを表示します。Activity名から該当の業務説明へ移動できます。原文は「原文を見る」から確認します。

この表示は記法候補のドッグフーディング用です。正式BD書式・Plugin・Graph v1の拡張として採用したものではありません。記法のないObjectでは従来の業務説明を表示します。

ObjectのInformationの後に `## State Transitions` を置き、PoC案A相当の `state-meta` と遷移表を明示します。このブランチでは比較PoC自体を含まないため、実際の全例は[隔離fixture](../tools/fixtures/state-transitions/purchase-request.md)を参照してください。セル内パイプ・改行、部分定義以外の完全性宣言、確定終端は今回の記法候補の対象外です。

- 状態変更・状態不変・記録を作成しない不成立・遷移先未決の制約を区別します。
- 未記載の操作を禁止にしません。自然文から遷移を追加せず、条件の意味やProcedure/Resultとの整合を自動判定しません。
- 破棄後や再申請失敗後の保存状態は未決のままです。CSVは「purchasedに変更しない」という既存原典の制約を表示し、状態不変を補完しません。
- 不正な宣言はドロワーで表示できない理由を通知し、相関図は維持します。Activity名の参照が見つからない場合も要確認と表示します。
- 表示は読取り専用で、原文や別の状態図を編集・保存する機能は追加しません。復元時は原文から宣言を再抽出します。

初回の最小実装は縦並びの操作一覧です。専用の状態遷移図、完全性検証、正式BD/Skillへの書式反映は含みません。
