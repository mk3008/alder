Supersedes the initial fixed-four-column layout at source1322f8e6. No deployment accompanies this source change.

Normal input/output relations form a directed graph. Iterative strongly-connected-component discovery identifies actual cycles. Every normal edge between components stays forward; within cycles, Activity document order and each Object's earliest-listed writer form an acyclic display ordering. Without a complete valid hint, stable IDs provide the tie-break. Longest-path ranks extend left to right without viewport wrapping. Vertical barycenter ordering cannot reverse forward edges. Original GraphJSON relations, meanings, arrows and exception paths are not rewritten. This is a display heuristic, not an execution-order definition. A cycle-cut relation is excluded from rank constraints, but may still happen to point right. Existing curved routing draws the original directions, including returns. Saved coordinates always win, including legacy grids and deliberate overlaps.
