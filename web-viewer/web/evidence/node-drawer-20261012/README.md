# Left node list and tab-strip sizing

Adopted left Drawer design, with latest color corrections: visible eye icons use currentColor; hidden eyes use the subdued foreground; category active colors match existing file tabs. Activity/Object rows contain an eye and a name only. Role headers retain the existing Who-colored person badge and a disclosure chevron; child Activity rows do not duplicate the person badge. No role-color editor or new connector-side rule is included.

The list provides Activity/Object/Role categories, name search and per-node visibility. Hidden entries remain listed; their names cannot reveal or navigate to them. Eye controls restore visibility. Scope-outside bulk changes every outside item in the current tab; mixed state shows a quiet visible count and the next bulk click shows all. Individual edits may follow. Objects are not automatically hidden when isolated.

Visibility is stored per tab as hidden IDs, including inside and outside nodes. Only visible nodes and edges with both endpoints visible are rendered, but all saved coordinates and routing/canvas bounds remain available. Existing global show/hide sessions migrate to per-tab IDs; removed dim/legacy boolean settings remain show, and explicit hide is preserved. Closed sample layout includes visibility and the camera state; new tabs do not inherit another tab's overrides.

Clicking a visible name selects its node/right Markdown and centers the node in the actual visible graph area without changing node positions or zoom. A persisted world-coordinate view inset permits centering near-origin nodes without negative scroll. Default inset is zero, preserving prior initial geometry. Graph selection updates category/group/search as needed and reveals the matching row; it does not force a closed list open. Opening the list reveals the existing selection. On narrow screens it is an overlay and closes before name navigation; Escape closes it and returns focus. Desktop left/right Drawers flank the graph. Role/category keyboard controls and eye-button accessible names/states are included.

The tab strip no longer forces a44px child into a44px border-box with an additional border. Its non-shrinking auto height accommodates tabs and a real horizontal scrollbar; vertical overflow is removed without cropping controls, and many-tab horizontal scrolling remains. The workspace uses remaining flex height instead of a fixed subtraction. Browser tests use one and nine tabs, light/dark,320/393/1280px, CSS zoom1/1.25 and an explicit17px scrollbar-width fixture. This is Linux Chrome geometry verification, not a Windows OS or native browser-zoom certification.

New DOM tests cover per-node/bulk/mixed behavior, hidden names, isolated Objects, role/search/icon rules, focus/Escape, per-tab isolation, restore and nonzero-inset exact centering/pinch/extent stability. New real-browser checks cover actual center geometry, Graph/list sync, mixed visibility, hidden names, colors, independent tabs, sample close/reload/reopen, mobile overlay and Escape. Existing routing/direction, Scope/Write, locks, input, preview storage and touch tests remain. Historical failed runs are retained, not rewritten as passes.

Validation is one initial run21/attempt1 after local full regression, strict/build and independent review, in one Ubuntu24.04job with a15minute limit, no added artifact/cache or rerun. Final CI results belong in the separately authorized progress record. No new preview deployment accompanies this source until explicitly approved. Physical Android and known native Drawer touch-scroll remain unverified.
