# 配置操作と初期配置の検証

比較基準は [b2b24750](https://github.com/mk3008/alder/commit/b2b247506ee59869eabdebfc2d6c1302214dc890)。同梱サンプルの25ノード・63関係を、Write優先なしで比較した。

## 変更

- ページを開くたび配置ロックがON。ノード上のドラッグは図の移動、短いクリック／タップは選択。解除すると座標を編集できる。解除状態は保存しない。
- Scope外は削除せず、設定ONで40%の濃さにする。選択と直接関連する項目は通常の濃さを保つ。旧hideOutsideのON/OFFをdimOutsideへ移行し、選択・座標・種別背景色・Who色を保持する。
- 初期配置は4列・360×180pxの間隔を基準に、接続ノードの距離が減る交換を行う。最大10周・50,000組比較・250,000隣接訪問で停止する。通常辺の総変位で向きを合わせるが、業務の実行順を推定する機能ではない。既存座標は重複していても保持し、欠損ノードのみ追加する。
- 障害物を迂回する場合も二次Bezier曲線に統一。矢印、例外破線、ラベル、ドラッグ追従を保持。曲線の極値とラベル幅をキャンバス範囲へ含める。

## 同一サンプルの4条件比較

| 配置 | 配線 | ノード重複 | 線の交差 | 線と他ノードの衝突 | 総経路長px | ラベル矩形重複 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 旧 | 旧 | 0 | 280 | 79 | 42,721 | 74 |
| 新 | 旧 | 0 | 75 | 16 | 20,424 | 29 |
| 旧 | 曲線 | 0 | 264 | 102 | 34,118 | 81 |
| 新 | 曲線 | 0 | 48 | 23 | 19,470 | 28 |

新配置と曲線の組合せでは旧版比で交差83%、経路長54%、ラベル矩形重複62%減。配置の占有範囲は1220×908pxから1340×1148pxへ広がる。端数行を反転するため、このサンプルの最上段は1ノードになる。

線の交差は、端点を共有しない2経路のサンプル線分の厳密交差数。衝突は14pxの余白と曲線近似誤差を含むルーター値。ラベルは max(30, 文字数×12)×18px の推定矩形で、ブラウザーの実字形計測ではない。全条件でラベルとノードの矩形重複は0。生データは [comparison.json](comparison.json)。

曲線化だけでは衝突が増える。新配置でも線と他ノードの衝突23、fallback経路21、ラベル同士の重複28が残る。完全な障害物回避や最適配置を保証しない。

再計測はweb-viewerで次を実行する。

```sh
node --experimental-strip-types web/compare-layout.mjs
```

比較用の旧ルーターは、このディレクトリのrouting-before.tsに固定した。実装では使わない。

## 検証の範囲

先行ローカル全回帰はロック・Scope半透明・曲線化後に成功。初期配置のモデルでは決定性・重複なし・1〜1000ノード・保存座標保持を確認した。初期配置後の最終全回帰は途中で結果取得が取り消され、完了未確認。完了済みstrict/buildと区別し、最終コードの全回帰・型・build・実Chromeは今回1回のCIを判定根拠とする。

Chrome用の検証は、default lock・mouse pan/選択・解除後drag・全曲線・Drawer wheel・保存再読込・Scope設定移行・320/393px表示、touch protocolとpinch/指離脱/lockを含む。実Android機器は自動試験の対象外。

旧run14のnative touch scrollは、単純overflow対照とDrawerの両方で入力が成立しなかった。今回この2件はnot-runとして理由を出力し、繰り返さない。未判定を成功に変更せず、実行する必須caseにfailed/blockedが1件でもあればCIを失敗させる。
