# Alder Viewerの使い方

[Viewerを開く](https://mk3008.github.io/alder/) · [Alderの導入・作成手順](../README.ja.md) · [Markdownの書き方](../docs/business-design-structure.ja.md)

業務設計書のMarkdownを開くと、業務（Activity）と、その業務が扱う人・もの・情報（Object）のつながりを図で確認できます。対応するチェックリストを追加すると、業務の説明とチェック項目を同じ画面で読み比べられます。

## まずサンプルを試す

ファイルを用意せずに、業務図とチェック項目の見え方を試せます。

1. 上部の「開く」から「サンプルを開く」を選びます。
2. 業務図が表示されたら、「チェックリストも開きますか？」の「チェックリストを開く」から「サンプルを開く」を選びます。
3. 全体図の「業務設計」Activity右端の詳細タブアイコンをクリック／タップまたはEnterで開き、詳細図で、右側の「業務内容」と「チェック項目」を切り替えて読み比べます。

チェックリストのサンプルは表示を試すための一部の項目です。業務全体の網羅や、正式な承認を示すものではありません。自分の文書を使うときは、次の手順へ進んでください。

## 自分の業務設計書を開く

上部の「開く」から、文書の置き場所に合う方法を選びます。

| 開き方 | 操作 |
| --- | --- |
| ファイルを開く | 端末にある業務設計書のMarkdownファイルを選びます。 |
| URLを開く | HTTPSのMarkdown本文URLを入力します。GitHubでは、ファイルの表示ページではなくRawのURLを使います。 |
| テキストを入力 | Markdown本文を貼り付けて「表示」を押します。 |

URLは、認証なしで取得でき、ブラウザーからの取得を許可したものに限ります。HTMLのページやリダイレクト先は取得できません。秘密情報を含むURLは入力しないでください。

開く原本は1つです。別の業務設計書を開くと原本を置き換え、以前の本文・未反映の編集・関連Checkは「保存文書の復旧」に残します。図を表示できない場合は、通知の理由と[Markdownの書き方](../docs/business-design-structure.ja.md)を確認してください。業務設計書をこれから作る場合は、[Alderの導入・作成手順](../README.ja.md)から始められます。

## チェックリストを続けて開く

業務設計書とチェックリストは、別々のMarkdownファイルです。まず業務設計書を開き、表示された案内から対応するチェックリストを選びます。

「チェックリストを開く」には「ファイルを開く」と「URLを開く」があります。未編集の同梱サンプルを表示している場合は、「サンプルを開く」も選べます。

チェックリストがなくても業務図は使えます。「あとで」を押すと案内が閉じます。歯車の表示設定を開いた場合も、図の領域を確保するため案内を閉じます。後から開くときは、文書ツールバーのチェックリストアイコンを使ってください。狭い画面では、文書の操作メニュー「…」内にあります。保存した文書を復元したときには、この案内は出ません。

読込後は、右側の「チェック項目」で確認できます。原典の参照が別の業務設計書を指していれば、関連付けを拒否して理由を表示します。対応を自動で確かめられない場合は、原典参照・業務別インデックス・本文を読み、「対応を確認して表示する」を押してください。関連付けの確認は、チェック項目の内容や人間レビュー状態の承認とは別です。

別のチェックリストに替えるときも、文書ツールバーから開きます。「チェックリストを閉じる」を選ぶと、その業務設計書との紐づけを解除します。チェックリストの元ファイルは削除しません。

## 図と本文を読む

「全体図」は閉じられない表示タブです。Activity右端の「詳細タブを開く」アイコンをクリック／タップ、またはTabで選んでEnter／Spaceを押すと、Activity名の詳細タブが開きます。Activity本体のクリック／タップはObjectと同じ選択操作です。同じActivityは重複せず、倍率・配置・選択は各タブで独立します。詳細タブを閉じても原本と関連Checkは残ります。

全体図はすべてのActivity・Object・相関を持ちます。Activity詳細には対象Activityと、直接Input/OutputでつながるObject・線だけが並びます。Objectを選ぶと右側で本文を確認できます。Scope外の項目も一覧と表示設定から確認できます。

図の業務やObjectを選ぶと、右側に名前と本文が表示されます。「業務内容」で業務設計書の該当箇所を、「チェック項目」で選んだ業務に対応する条件・期待結果・人間レビュー状態を読めます。右上のドロワーボタンで、本文欄を開閉できます。

左上の一覧ボタンからは、業務・Object・ロール別に名前を探せます。一覧の名前を選ぶと、図の該当箇所へ移動します。「指摘」では、業務設計書に記載された要確認・要修正や困りごとを確認できます。

図の選択・移動はマウスやタッチで操作します。メニューは矢印キーで項目を選び、Escapeで閉じられます。ヘルプのリンクは新しいタブで開くので、表示中の業務図を残したまま説明を読めます。

## 図の表示を調整する

右下の「＋」「−」で拡大・縮小できます。タッチ操作では、2本の指を広げる・狭める操作でも倍率を変えられます。

配置は最初はロックされています。鍵ボタンで解除すると、ActivityとObjectの本体をドラッグして移動できます。Activity本体を押すと選択し、右端のアイコンを押すと詳細タブを開きます。ロック中は、図形の上からでも図をスクロールできます。

歯車の表示設定では、スコープ外や例外線の表示、Writeの優先表示、選択した項目の結線だけを表示する設定を切り替えられます。左の一覧では、目のアイコンから項目ごとに表示・非表示を選べます。

配置を戻すには、歯車の「レイアウトを初期値に戻す」を選びます。現在の文書の配置・倍率・表示位置が初期状態に戻ります。本文や他のタブは変更しません。

## 原文を確認・編集する

文書ツールバーの文書アイコン「原文を見る／編集する」から、業務設計書の全文を開けます。どの表示タブから開いても同じ原本を編集します。本文を直して「反映する」を押すと、ブラウザーに保存して図を更新します。元ファイルやURL上の文書は書き換えません。

図に未反映の編集がある状態で閉じる場合は、編集を保持して閉じるか、そのまま編集を続けるかを選びます。業務設計書の本文を変更した後は、チェックリストとの対応を再確認する必要があります。

チェックリスト本文の編集はViewerでは行いません。元のMarkdownを編集したら、チェックリストを開き直してください。

## 図を画像にする

文書ツールバーの「グラフ全体をPNGで保存」で、表示対象の図全体を画像にできます。画面の外にある図形も含みます。「グラフ全体をPNGでコピー」は、クリップボードへ画像をコピーする操作です。ブラウザーの対応や権限によってコピーできない場合は、PNG保存を使ってください。

図形や線の表示設定は画像にも反映されます。画像に含めたい項目を表示してから出力してください。

## 取得元から読み直す・共有する

文書ツールバーの更新アイコンは、現在の文書を元ファイルやURLから読み直します。ブラウザー内で編集している場合は、破棄する前に確認します。テキスト入力と同梱サンプルでは、この更新操作は使えません。

URLから開いた未編集の文書では、共有アイコンから取得元の共有リンクをコピーできます。リンクに含まれるのは取得元URLだけで、ブラウザー内の編集・配置・チェックリストは含まれません。元URLの内容が変わると、受け取った人が読む内容も変わります。共有できない場合は、ボタンを押すと理由を確認できます。

## 保存とエラーに対処する

開いた文書・チェックリスト・表示状態は、そのブラウザーに保存します。復元のために元URLを自動取得することはありません。ローカルの本文をAlderのサーバーへ送信しません。URLを開く・更新する場合には、指定した配信元への取得通信が発生します。

旧版の複数文書や、原本の切替前の保存内容は「保存文書の復旧」から選び直せます。同欄の「全保存内容をJSONで退避」で、本文・関連Check・表示状態を控えられます。

ブラウザーの保存データを削除すると、文書や編集内容も失われます。共有端末には機密文書を残さず、重要な本文は別途保管してください。

読込に失敗した場合は、通知の理由を確認して選び直してください。既存の業務図・関連付け・編集中の本文は保持します。保存エラーが出た場合は、その画面を閉じる前に、通知内のファイル保存やコピーで必要な本文を退避してください。図の配置まで退避できる機能ではありません。
